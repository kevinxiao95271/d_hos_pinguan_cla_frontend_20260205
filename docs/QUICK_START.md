# 快速启动指南

## 前提条件

1. 确保后端服务已启动
   - 后端地址: http://localhost:6031
   - Swagger文档: http://localhost:6031/swagger-ui/index.html

2. 确保已安装 Node.js 和 npm
   ```bash
   node --version  # 应该 >= 16
   npm --version   # 应该 >= 8
   ```

## 启动步骤

### 1. 安装依赖（首次运行）
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问系统
打开浏览器访问: http://localhost:6039

## 测试流程

### 场景1: 参赛者报名流程

1. **登录**
   - 点击"参赛者A"测试账号按钮
   - 或手动输入: 13800000011 / Contestant A
   - 点击登录

2. **查看赛事**
   - 进入系统后，点击左侧"赛事列表"
   - 查看可报名的赛事

3. **报名**
   - 点击"立即报名"按钮
   - 填写报名表（4个步骤）
     - 步骤1: 填写项目名称，添加参与人员和辅导员
     - 步骤2: 填写活动说明
     - 步骤3: 填写项目摘要
     - 步骤4: 上传资料
   - 点击"提交报名"

4. **查看我的赛事**
   - 点击左侧"我的赛事"
   - 查看报名详情、评审结果等

### 场景2: 评审专家评分流程

1. **登录**
   - 点击"评审专家A"测试账号按钮
   - 或手动输入: 13800000021 / Reviewer A

2. **查看任务**
   - 进入系统后，查看评审任务列表
   - 可以按阶段和状态筛选

3. **评分**
   - 点击"评分"按钮
   - 填写各项评分（0-100分）
   - 填写亮点和不足之处
   - 提交评分

### 场景3: 赛事组委会管理流程

1. **登录**
   - 点击"组委会A"测试账号按钮
   - 或手动输入: 13800000041 / CommitteeAdmin A

2. **创建赛事**
   - 点击"创建赛事"
   - 输入赛事名称
   - 上传资料模板（可选）
   - 提交创建

3. **管理赛事**
   - 点击赛事列表中的"管理"按钮
   - 进入赛事详情页面
   - 可以进行以下操作：
     - 报名与分组
     - 评委分配
     - 查看评分情况
     - 入围管理等

4. **报名管理**
   - 在"报名与分组"标签
   - 筛选报名项目
   - 可以变更分组、批量分类
   - 点击"自动分组"自动分配

5. **评委分配**
   - 在"评委分配"标签
   - 查看各分组的评委情况
   - 点击"自动分配"自动分配评委
   - 或手动设置评委

### 场景4: 系统运维管理流程

1. **登录**
   - 点击"运维A"测试账号按钮
   - 或手动输入: 13800000051 / Ops A

2. **机构管理**
   - 点击"机构管理"
   - 可以新建、编辑、删除机构
   - 可以导入Excel批量添加机构

3. **字典管理**
   - 点击"字典管理"
   - 切换不同类型的字典
   - 可以新建、编辑、删除字典项

4. **数据源管理**
   - 点击"数据源管理"
   - 查看当前数据库
   - 可以切换到其他测试数据库

5. **系统设置**
   - 点击"系统设置"
   - 配置评审专家最大负荷
   - 配置各组别的分组数量
   - 配置入围比例

## 常见问题

### Q1: 前端启动失败
**A**: 检查是否已安装依赖
```bash
npm install
```

### Q2: 登录后显示空白页
**A**: 检查后端服务是否正常运行
```bash
# 访问后端健康检查
curl http://localhost:6031/api/health
```

### Q3: API请求失败
**A**: 
1. 检查后端服务是否启动
2. 检查网络代理配置
3. 查看浏览器控制台错误信息

### Q4: 文件上传失败
**A**: 
1. 检查文件大小是否超过50MB
2. 检查文件格式是否正确
3. 检查后端文件上传配置

### Q5: 参赛者登录失败
**A**: 这是已知问题，后端返回500错误，需要后端修复。其他角色登录正常。

## 开发调试

### 查看网络请求
1. 打开浏览器开发者工具 (F12)
2. 切换到 Network 标签
3. 查看 API 请求和响应

### 查看状态管理
1. 安装 Vue DevTools 浏览器插件
2. 打开开发者工具
3. 切换到 Vue 标签
4. 查看 Pinia 状态

### 查看路由信息
在浏览器控制台输入:
```javascript
// 查看当前路由
console.log(window.$router.currentRoute.value)

// 查看所有路由
console.log(window.$router.getRoutes())
```
