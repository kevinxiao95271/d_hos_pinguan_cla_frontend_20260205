# 🔍 赛事列表字段不匹配问题诊断

## 📋 问题描述

参赛者查看"赛事列表"时：
- **报名时间** 显示为 `-`
- **当前阶段** 显示为空

---

## 🔎 问题原因

### API接口

**接口地址**: `GET /api/competitions`

**后端实际返回的字段名**：
```json
{
  "id": 21,
  "name": "2026浙江品管大赛",
  "stage": "REGISTER",              // ← 注意：不是 currentStage
  "registerStart": "2026-02-01...", // ← 注意：不是 registrationStartTime
  "registerEnd": "2026-02-26...",   // ← 注意：不是 registrationEndTime
  "bookReviewStart": "...",
  "bookReviewEnd": "...",
  "interviewStart": "...",
  "interviewEnd": "...",
  "finalStart": "...",
  "finalEnd": "...",
  "createdAt": "2026-02-05..."
}
```

### 前端期望的字段名

**文件**: `src/views/contestant/Competitions.vue`

```vue
<!-- 报名时间 -->
<span>{{ formatDateRange(item.registrationStartTime, item.registrationEndTime) }}</span>
                            ↑                          ↑
                         不存在!                     不存在!

<!-- 当前阶段 -->
<span>{{ getStageText(item.currentStage) }}</span>
                           ↑
                        不存在!
```

---

## ⚠️ 字段不匹配对照表

| 显示内容 | 前端期望字段 | 后端实际字段 | 状态 |
|---------|------------|------------|------|
| 报名开始时间 | `registrationStartTime` | `registerStart` | ❌ 不匹配 |
| 报名结束时间 | `registrationEndTime` | `registerEnd` | ❌ 不匹配 |
| 当前阶段 | `currentStage` | `stage` | ❌ 不匹配 |
| 书审开始时间 | `bookReviewStart` | `bookReviewStart` | ✅ 匹配 |
| 书审结束时间 | `bookReviewEnd` | `bookReviewEnd` | ✅ 匹配 |
| 面谈开始时间 | `interviewStart` | `interviewStart` | ✅ 匹配 |
| 面谈结束时间 | `interviewEnd` | `interviewEnd` | ✅ 匹配 |
| 决赛开始时间 | `finalStart` | `finalStart` | ✅ 匹配 |
| 决赛结束时间 | `finalEnd` | `finalEnd` | ✅ 匹配 |

## 🔧 解决方案

### 方案1: 修改前端代码（推荐）✅

**优点**: 
- 不影响后端，改动最小
- 立即生效

**修改文件**: `src/views/contestant/Competitions.vue`

```vue

  <span class="label">报名时间：</span>

  <span class="label">当前阶段：</span>
  <span>{{ getStageText(item.currentStage) }}</span>
</div>

<!-- 修改后 -->

  <span class="label">报名时间：</span>
  <span>{{ formatDateRange(item.registerStart, item.registerEnd) }}</span>
</div>
<div class="meta-item">
  <span class="label">当前阶段：</span>
  <span>{{ getStageText(item.stage) }}</span>
</div>
```

**同时修改标签显示**：
```vue
<!-- 修改前 -->
<el-tag :type="getStageType(item.currentStage)">
  {{ getStageText(item.currentStage) }}
</el-tag>

<!-- 修改后 -->
<el-tag :type="getStageType(item.stage)">
  {{ getStageText(item.stage) }}
</el-tag>
```

**修改判断逻辑**：
```javascript
// 修改前

  return item.currentStage === 'REGISTRATION'
}

// 修改后
const canRegister = (item) => {
  return item.stage === 'REGISTER'  // 注意值也改了
}
```

## 📊 后端阶段值映射

| 后端值 | 前端期望值 | 中文含义 | 前端是否需要适配 |
|--------|-----------|---------|-----------------|
| `REGISTER` | `REGISTRATION` | 报名中 | ✅ 需要 |
| `BOOK` | `BOOK` | 书审中 | ✅ 一致 |
| `INTERVIEW` | `INTERVIEW` | 面谈中 | ✅ 一致 |
| `FINAL` | `FINAL` | 决赛中 | ✅ 一致 |

**注意**: 报名阶段的值不同！
- 后端: `REGISTER`
- 前端期望: `REGISTRATION`

### 2. 脚本部分修改

```javascript
const getStageType = (stage) => {
  const map = {
    'REGISTER': 'success',    // ✅ 修复：使用 REGISTER 而不是 REGISTRATION
    'BOOK': 'warning',
    'INTERVIEW': 'warning',
    'FINAL': 'danger'
  }
  return map[stage] || 'info'
}

const getStageText = (stage) => {
  const map = {
    'REGISTER': '报名中',     // ✅ 修复：使用 REGISTER 而不是 REGISTRATION
    'BOOK': '书审中',
    'INTERVIEW': '面谈中',
    'FINAL': '决赛中'
  }
  return map[stage] || stage
}

const canRegister = (item) => {
  return item.stage === 'REGISTER'  // ✅ 修复：使用 stage 和 REGISTER
}
```

## 📝 总结

### 问题根源
- 前端使用的字段名与后端实际返回的字段名不一致
- 阶段值的枚举值不同（`REGISTRATION` vs `REGISTER`）

### 解决方案
- 修改前端代码以匹配后端实际字段名
- 更新阶段值映射

### 影响范围
- 仅影响 `src/views/contestant/Competitions.vue` 一个文件
- 不影响其他模块和API
