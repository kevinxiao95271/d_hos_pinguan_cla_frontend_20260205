## 🚧 技术难点

### 1. 文件预览（难度最高 ⭐⭐⭐⭐）

**问题：**
- Office文档（Word、Excel、PPT）预览复杂
- 需要考虑多种文件格式
- 要在新标签页打开且禁止下载

**推荐方案：**
```
后端将Office文档转为PDF + 前端使用pdf.js预览
```

**其他方案：**
- 方案A：使用vue-office前端预览（库体积大）
- 方案B：使用在线预览服务（依赖外部，不稳定）

### 2. 禁用下载（难度中等 ⭐⭐⭐）

**问题：**
- 浏览器原生预览很难完全禁止下载
- 用户可通过开发者工具获取URL

**解决方案：**
- 前端：隐藏下载按钮、禁用右键
- **后端（核心）：** 文件URL加时效Token、权限验证
- 水印标记（可选）

**注意：** 完全防止下载不可能，只能增加难度！

### 3. 大文件上传（难度中等 ⭐⭐⭐）

**问题：**
- 成果说明书可能几十MB
- 网络不稳定易失败

**解决方案：**
- 分片上传（2MB一片）
- 断点续传
- 进度显示和失败重试

## 🔄 后端需要提供

### 必需API（P0）
1. `POST /api/files/upload` - 上传文件
2. `DELETE /api/files/{fileId}` - 删除文件
3. `GET /api/files/{fileId}/preview` - 获取预览URL（带Token）
4. `GET /api/files/registration/{registrationId}` - 获取报名的文件列表

### 现有API需要修改
所有返回报名数据的API，增加 `materials` 字段：
```json
{
  "materials": {
    "applicationForm": {...},     // 报名表
    "achievementDoc": {...},      // 成果说明书
    "supportingDocs": [...]       // 佐证材料数组
  }
}
```

### 后端核心功能
1. ✅ 文件存储到Minio
2. ✅ **权限控制**（最重要！）
3. ✅ **预览URL生成**（带时效Token）
4. ✅ Office文档转PDF（推荐）
5. ✅ 文件格式和大小验证
6. ✅ 访问日志记录

## 💡 核心建议

### 最关键的3个决策

1. **文件预览方案 ⭐⭐⭐⭐⭐**
   - **推荐：** 后端转PDF + pdf.js
   - 优点：体验统一、前端简单、兼容性好
   - 需要：后端实现Office→PDF转换

2. **禁用下载策略 ⭐⭐⭐⭐**
   - **推荐：** 后端Token验证 + 前端UI限制
   - 重点：后端权限控制
   - 现实：无法完全禁止，只能增加难度

3. **文件上传方式 ⭐⭐⭐**
   - **推荐：** Element Plus Upload + 自定义封装
   - 考虑：大文件需要分片上传
   - 体验：实时进度显示 + 失败重试
