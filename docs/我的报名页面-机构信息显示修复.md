# 我的报名页面 - 机构信息显示修复

## 问题描述

### 1. 机构信息不显示
**现象**：
- 列表页面的"医疗机构"和"机构等级"列显示为空（"-"）
- 但点击"查看详情"进入详情页，这些信息是正常显示的

**原因**：
- 详情接口 `/api/registrations/{id}` 返回的数据结构中，机构信息在嵌套的 `institution` 对象内
- 列表接口 `/api/registrations/my` 也返回了嵌套的 `institution` 对象，但前端代码直接读取平铺字段 `institutionName` 和 `institutionLevel`
- 由于字段不存在，显示为空

### 2. 操作列过宽
**现象**：
- 操作列宽度为 250px，占用过多空间
- 按钮之间间距大，不够紧凑

## 解决方案

### 1. 修复机构信息显示

**文件**: `src/views/contestant/MyRegistrations.vue`

**修改**: 在 `loadData` 函数中，处理 API 返回的数据，从嵌套的 `institution` 对象中提取字段

```javascript
const loadData = async () => {
  loading.value = true
  try {
    const res = await getMyRegistrations()
    if (res.success) {
      const rawData = res.data || []
      
      // 处理机构信息：从 institution 对象中提取 name 和 level
      registrations.value = rawData.map(item => {
        return {
          ...item,
          institutionName: item.institution?.name || item.institutionName || '-',
          institutionLevel: item.institution?.level || item.institutionLevel || ''
        }
      })
      
      if (registrations.value.length === 0) {
        ElMessage.info('暂无报名记录')
      }
    } else {
      ElMessage.error(res.message || '加载失败')
    }
  } catch (error) {
    console.error('加载报名列表失败:', error)
    ElMessage.error('加载报名列表失败')
  } finally {
    loading.value = false
  }
}
```

**逻辑**：
1. 优先从 `item.institution?.name` 获取机构名称
2. 如果不存在，尝试 `item.institutionName`（兼容旧数据）
3. 都不存在则显示 "-"
4. 机构等级同理，但空值显示为空字符串（el-tag 会显示 "-"）

### 2. 优化操作列宽度

**修改**：
1. 将操作列宽度从 `250px` 调整为 `200px`
2. 使用 `<el-space>` 包裹按钮，设置 `wrap` 属性允许自动换行
3. 设置 `:size="4"` 减小按钮间距

```vue
<el-table-column label="操作" width="200" fixed="right">
  <template #default="{ row }">
    <el-space :size="4" wrap>
      <template v-if="row.status === 'DRAFT'">
        <el-button type="primary" size="small" @click="editRegistration(row.id)">
          编辑
        </el-button>
        <el-button type="success" size="small" @click="submitRegistration(row.id)">
          提交
        </el-button>
      </template>
      <template v-else-if="row.status === 'SUBMITTED'">
        <el-button size="small" disabled style="cursor: not-allowed; opacity: 0.6;">
          已提交
        </el-button>
      </template>
      <el-button size="small" @click="viewDetail(row.id)">
        查看详情
      </el-button>
      <el-button v-if="row.status === 'SUBMITTED'" size="small" @click="viewResults(row.id)">
        查看评审结果
      </el-button>
    </el-space>
  </template>
</el-table-column>
```

**优势**：
- 节省空间：从 250px 减少到 200px
- 自动换行：按钮过多时自动换到下一行，避免溢出
- 紧凑布局：4px 的小间距让界面更精致

// API 返回（同上）

## 总结

1. **机构信息修复**：
   - 通过数据转换，从嵌套结构中提取字段
   - 兼容新旧数据格式
   - 避免显示空值

2. **UI 优化**：
   - 减少操作列宽度，节省空间
   - 使用 `el-space` 实现自适应布局
   - 提升视觉紧凑度

3. **兼容性**：
   - 保持与详情页数据结构一致
   - 支持后端返回不同格式的数据
   - 确保代码健壮性（使用可选链 `?.` 和默认值）
