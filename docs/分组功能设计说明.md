# 分组功能设计说明

## 功能概述

书审分组页面提供两种分组方式：
1. **自动分组** - 自动处理一整类项目
2. **批量分类** - 手动勾选后批量修改分组

---

## 1. 自动分组（Auto Group）

### 设计意图
**按组别自动处理符合条件的所有项目，与勾选无关**

### 操作流程
1. 用户在筛选条件中选择"竞赛组别"（基层组/综合组/进阶组）
2. 点击"自动分组"按钮
3. 系统自动将该组别的所有项目分配到指定前缀的分组编号

### 前端实现

```javascript
// src/views/committee/book/Registration.vue

const autoGroup = async () => {
  // 1. 必须先选择竞赛组别
  if (!filters.groupType) {
    ElMessage.warning('请先选择竞赛组别再进行自动分组')
    return
  }
  
  // 2. 根据组别确定分组前缀
  const prefixMap = {
    'BASIC': 'A',           // 基层组 → A1, A2, A3...
    'COMPREHENSIVE': 'B',   // 综合组 → B1, B2, B3...
    'ADVANCED': 'C'         // 进阶组 → C1, C2, C3...
  }
  
  // 3. 调用自动分组API
  await autoGroupRegistrations({
    competitionId: filters.competitionId,
    groupType: filters.groupType,     // ⭐ 关键：指定要处理的组别
    groupPrefix: prefixMap[filters.groupType],
    groupSize: 25
  })
}
```

### 后端API

**接口：** `POST /api/admin/registrations/auto-group`

**参数：**
```json
{
  "competitionId": 1,
  "groupType": "BASIC",      // ⭐ 关键：只处理这个组别的项目
  "groupPrefix": "A",
  "groupSize": 25
}
```

**期望行为：**
- ✅ 只处理 `groupType=BASIC` 的所有项目
- ✅ 按每组25人自动分配到A1, A2, A3...
- ✅ 其他组别（综合组、进阶组）的项目不受影响

**特点：**
- 🎯 处理范围：该组别的**所有项目**（不管是否勾选）
- 🎯 依据：筛选条件中的`groupType`参数
- 🎯 无需勾选：自动批量处理

---

## 2. 批量分类（Batch Classify）

### 设计意图
**手动勾选项目后，批量修改它们的分组编号**

### 操作流程
1. 用户在表格中勾选要修改的项目（可以勾选多个）
2. 点击"批量分类"按钮
3. 在弹窗中输入新的分组编号（如A1, B2等）
4. 系统只修改勾选的这些项目

### 前端实现

```javascript
// src/views/committee/book/Registration.vue

const batchClassify = () => {
  // 1. 必须先勾选项目
  if (selectedRegistrations.value.length === 0) {
    ElMessage.warning('请先选择要批量分类的项目')
    return
  }
  
  // 2. 检查所有选中项目的组别是否一致
  const firstGroupType = selectedRegistrations.value[0].groupType
  const allSameGroupType = selectedRegistrations.value.every(r => r.groupType === firstGroupType)
  
  if (!allSameGroupType) {
    ElMessage.error('批量分类只能在同一竞赛组别内进行')
    return
  }
  
  // 3. 调用批量分类API
  await batchClassifyRegistrations({
    registrationIds: selectedRegistrations.value.map(r => r.registrationId),
    groupCode: changeGroupForm.groupCode  // 用户输入的分组编号
  })
}
```

### 后端API

**接口：** `POST /api/admin/registrations/batch-classify`

**参数：**
```json
{
  "registrationIds": [1, 13, 31, 33],  // ⭐ 关键：只处理这些ID的项目
  "groupCode": "A3"
}
```

**期望行为：**
- ✅ 只修改指定ID的项目的分组编号
- ✅ 其他项目完全不受影响

**特点：**
- 🎯 处理范围：用户**勾选的项目**
- 🎯 依据：前端传递的`registrationIds`列表
- 🎯 必须勾选：不勾选无法操作

## 两种方式对比

| 对比项 | 自动分组 | 批量分类 |
|---|---|---|
| **触发条件** | 选择组别筛选条件 | 勾选项目 |
| **处理范围** | 该组别的所有项目 | 只处理勾选的项目 |
| **参数依据** | `groupType` | `registrationIds` |
| **分组规则** | 自动按每组N人分配 | 手动指定分组编号 |
| **是否需要勾选** | 否 | 是 |
| **典型场景** | 初次大批量分组 | 调整个别项目的分组 |

## 正确实现

### 自动分组API应该这样实现

```java
public void autoGroup(AutoGroupRequest request) {
    // ✅ 关键：只查询指定groupType的项目
    List<Registration> registrations = registrationRepository
        .findByCompetitionIdAndGroupType(
            request.getCompetitionId(),
            request.getGroupType()  // ⚠️ 使用groupType参数筛选
        );
    
    // ✅ 只对这些项目进行分组
    int groupNumber = 1;
    int count = 0;
    
    for (Registration reg : registrations) {
        reg.setGroupCode(request.getGroupPrefix() + groupNumber);
        count++;
        
        if (count % request.getGroupSize() == 0) {
            groupNumber++;
        }
    }
    
    registrationRepository.saveAll(registrations);
}
```

**核心要点：**
- 查询条件必须包含 `groupType`
- 只对查询出来的项目进行分组
- 其他组别的项目完全不受影响
