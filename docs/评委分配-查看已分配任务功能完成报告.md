## 📋 功能概述

在书审、面谈、决赛三个阶段的评委分配页面，添加了"查看已分配任务"功能，方便赛事组委会查看当前阶段已经分配的所有评审任务。

## 🔧 技术实现

### API 调用

使用现有的 `getReviewTasksByStage` API：

```javascript
// 从 @/api/admin 导入
import { getReviewTasksByStage } from '@/api/admin'

// 调用示例
const res = await getReviewTasksByStage({
  competitionId: competitionId.value,
  stage: 'BOOK' // 或 'INTERVIEW' 或 'FINAL'
})
```

### 数据结构

API 返回的任务数据格式：

```javascript
{
  success: true,
  data: [
    {
      id: 115,
      registrationId: 106,
      projectName: "护理交接班规范化-1",
      institutionName: "浙江大学医学院附属第二医院",
      groupType: "BASIC",
      groupCode: "A1",
      reviewerId: 14,
      reviewerName: "李明华",
      reviewerTitle: "主任医师",
      reviewerInstitutionName: "浙江省中医院",
      status: "SCORED", // PENDING/CONFIRMED/SCORED
      stage: "BOOK"
    },
    // ... 更多任务
  ]
}
```

### 状态映射

- `PENDING`: 待评审（蓝色标签）
- `CONFIRMED`: 已确认（紫色标签）
- `SCORED`: 已评分（绿色标签）

### 组别映射

- `BASIC`: 基层组（绿色标签）
- `COMPREHENSIVE`: 综合组（蓝色标签）
- `ADVANCED`: 进阶组（橙色标签）

## 🔍 代码质量

### 代码复用
- 三个页面使用相同的实现模式
- 保持代码风格一致
- 易于维护和扩展

### 错误处理
```javascript
try {
  const res = await getReviewTasksByStage({...})
  if (res.success) {
    allAssignedTasks.value = res.data || []
  } else {
    ElMessage.error(res.message || '加载失败')
    allAssignedTasks.value = []
  }
} catch (error) {
  console.error('❌ 加载已分配任务失败:', error)
  ElMessage.error('加载失败，请检查网络')
  allAssignedTasks.value = []
} finally {
  loadingAssignedTasks.value = false
}
```

### 日志记录
- 成功加载时输出日志：`✅ 加载所有已分配任务: 15 条`
- 失败时输出错误：`❌ 加载已分配任务失败:`

## 📝 使用说明

### 组委会用户操作流程

1. **登录系统**
   - 使用组委会账号登录

2. **进入评委分配页面**
   - 选择对应阶段（书审/面谈/决赛）
   - 点击"评委分配"菜单

3. **查看已分配任务**
   - 点击页面头部的"查看已分配任务"按钮
   - 弹窗显示所有已分配的评审任务

4. **查看任务详情**
   - 在表格中查看每个任务的详细信息
   - 包括项目名、评委名、状态等

5. **关闭弹窗**
   - 点击"关闭"按钮或右上角的 X

## 🎯 业务价值

### 1. 提升管理效率
- 组委会可以快速查看当前阶段的所有评委分配情况

- 在自动分配前查看现有分配情况
- 在手动分配时避免重复分配
- 为调整分配策略提供数据支持

### 4. 数据透明
- 所有分配记录可查
- 支持审计和追溯
- 提高管理透明度
