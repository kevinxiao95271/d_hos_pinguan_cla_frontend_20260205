## ⚠️ 发现的问题

### 问题1: 报名时间显示为 "-"

**原因**: 字段名不匹配

| | 前端期望 | 后端实际 |
|---|---------|---------|
| 报名开始 | `registrationStartTime` | `registerStart` |
| 报名结束 | `registrationEndTime` | `registerEnd` |

**结果**: 前端无法读取到报名时间，显示 "-"

### 问题2: 当前阶段显示为空

**原因**: 字段名不匹配

| | 前端期望 | 后端实际 |
|---|---------|---------|
| 当前阶段 | `currentStage` | `stage` |

**结果**: 前端无法读取到阶段信息，显示为空

### 问题3: 阶段值不匹配

**原因**: 枚举值不同

| 阶段 | 前端期望 | 后端实际 |
|-----|---------|---------|
| 报名 | `REGISTRATION` | `REGISTER` |

**结果**: 阶段映射失败，无法判断是否可报名

## 🔧 修复方案

### 修改文件

`src/views/contestant/Competitions.vue`

### 修复1: 模板中的字段名

```vue
<!-- ❌ 修复前 -->
<el-tag :type="getStageType(item.currentStage)">
  {{ getStageText(item.currentStage) }}

```

### 修复2: 阶段映射函数

```javascript
// ❌ 修复前
const getStageType = (stage) => {
  const map = {
    'REGISTRATION': 'success',  // 错误：后端不返回这个值
    'BOOK': 'warning',
    'INTERVIEW': 'warning',
    'FINAL': 'danger'
  }
  return map[stage] || 'info'
}

const getStageText = (stage) => {
  const map = {
    'REGISTRATION': '报名中',  // 错误：后端不返回这个值
    'BOOK': '书审中',
    'INTERVIEW': '面谈中',
    'FINAL': '决赛中'
  }
  return map[stage] || stage
}

const canRegister = (item) => {
  return item.currentStage === 'REGISTRATION'  // 错误：字段名和值都不对
}

// ✅ 修复后
const getStageType = (stage) => {
  const map = {
    'REGISTER': 'success',  // 正确：匹配后端返回值
    'BOOK': 'warning',
    'INTERVIEW': 'warning',
    'FINAL': 'danger'
  }
  return map[stage] || 'info'
}

const getStageText = (stage) => {
  const map = {
    'REGISTER': '报名中',  // 正确：匹配后端返回值
    'BOOK': '书审中',
    'INTERVIEW': '面谈中',
    'FINAL': '决赛中'
  }
  return map[stage] || stage
}

const canRegister = (item) => {
  return item.stage === 'REGISTER'  // 正确：使用正确的字段名和值
}
```
