## 💡 数据来源分析

### 机构等级的赋值时机

**推测流程：**

1. **用户注册时选择机构**
   - 参赛者在注册页面选择医疗机构
   - 前端调用：`getInstitutionsByRegionAndType` 获取机构列表
   - 机构列表包含 `level` 字段

2. **创建报名时关联机构**
   - 报名记录保存机构ID
   - 数据库外键关联到 `institution` 表

3. **查询列表时自动填充**
   - 后端查询报名列表时，JOIN 机构表
   - 自动填充 `institutionLevel` 字段到响应DTO

### 后端实现（推测）

**实体关联：**
```java
// Registration.java
@ManyToOne
@JoinColumn(name = "institution_id")
private Institution institution;
```

**DTO映射：**
```java
// RegistrationFilterItem.java
private String institutionLevel;  // 从 institution.level 填充
```

**Service查询：**
```java
// RegistrationService.java
List<Registration> registrations = repository.findByFilters(...);
for (Registration reg : registrations) {
    item.setInstitutionLevel(reg.getInstitution().getLevel());
}
```
