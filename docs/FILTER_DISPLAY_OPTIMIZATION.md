# 🎯 筛选条件展示优化

## 问题描述

用户反馈：选中筛选条件后，只能看到一个"x"（清除按钮），看不到选中的具体内容。例如选择了"基层组"，只显示"x"，看不到"基层组"三个字。

## 解决方案

### 1. ✅ 增加下拉框宽度

为所有 `el-select` 和 `el-input` 设置明确的宽度，确保选中的文字完整显示：

```vue
<!-- 医疗机构 -->
<el-input style="width: 200px" />

<!-- 竞赛组别 -->
<el-select style="width: 140px" />

<!-- 分组 -->
<el-select style="width: 120px" />

<!-- 项目名称 -->
<el-input style="width: 200px" />

<!-- 品管工具 -->
<el-select style="width: 180px" />
```

### 2. ✅ 添加筛选条件标签展示

在筛选表单下方添加一个标签区域，清晰展示当前已选中的所有筛选条件：

```vue
<div v-if="hasActiveFilters" class="active-filters">
  <span class="filter-label">当前筛选：</span>
  <el-tag closable @close="clearFilter">
    竞赛组别：基层组
  </el-tag>
  <el-tag closable @close="clearFilter">
    品管工具：PDCA
  </el-tag>
  <!-- ... 其他筛选条件 -->
</div>
```

#### 特性：
- ✅ 仅在有筛选条件时显示
- ✅ 每个标签显示"字段名：值"
- ✅ 不同类型使用不同颜色（竞赛组别=绿色，分组=橙色，品管工具=灰色等）
- ✅ 点击标签的 ❌ 可直接移除该筛选条件并自动刷新列表
- ✅ 浅灰背景，圆角设计，视觉清晰

### 3. ✅ 实现的功能

#### `hasActiveFilters` 计算属性
检查是否有任何筛选条件处于激活状态：

```javascript
const hasActiveFilters = computed(() => {
  return !!(
    filters.institutionName ||
    filters.groupType ||
    filters.groupCode ||
    filters.projectName ||
    filters.methodCode
  )
})
```

#### `getMethodLabel` 方法
根据 `methodCode` 获取中文标签：

```javascript
const getMethodLabel = (code) => {
  const method = dictionaries.methods.find(m => m.code === code)
  return method ? method.label : code
}
```

#### 快速清除筛选条件
点击标签的关闭按钮，立即清除并刷新：

```vue
<el-tag
  closable
  @close="filters.groupType = ''; loadRegistrations()"
>
  竞赛组别：基层组
</el-tag>
```

```

│ 竞赛组别：[基层组 ▼]  分组：[A1 ▼]  品管工具：[PDCA ▼]     │  ← 下拉框宽度足够
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 当前筛选：[竞赛组别：基层组 ×] [分组：A1 ×] [品管工具：PDCA ×]│  ← 标签清晰展示

```

## 交互优化

1. **下拉框内选中**：文字完整显示，不会被截断
2. **标签展示区域**：
   - 自动换行（`flex-wrap: wrap`）
   - 仅在有筛选条件时显示
   - 浅灰背景（`#f5f7fa`），区分表单区
3. **快速清除**：
   - 点击标签的 ×：清除单个筛选条件
   - 点击"重置"按钮：清除所有筛选条件
