# 报名草稿保存问题修复

## 📋 问题描述

**用户反馈**：
> 我的报名我选了赛事了 然后点击下一步 然后又点击左侧导航栏 然后又点击编辑按钮 赛事又变成需要选择了，之前选过的数据没有存下来。

**问题场景**：
1. 用户访问 `/contestant/register/new`（新建报名）
2. 选择赛事
3. 点击"下一步"（数据已保存到后端）
4. 点击左侧导航栏离开页面
5. 再次点击"编辑"按钮
6. **发现赛事选择丢失了，又变成空白**

### 技术细节

**问题代码** (修复前):

**问题**：
- ✅ 数据成功保存到后端（报名ID: 5）
- ✅ 设置了 `registrationId.value = 5`
- ❌ **URL仍然是 `/contestant/register/new`**
- ❌ 页面刷新或重新进入时，`registrationId` 会被重新初始化为 `null`
- ❌ 无法加载已保存的数据

## ✅ 解决方案

### 核心修复

**创建报名成功后，立即更新URL为编辑模式**

**修复后的代码**:
```javascript
const saveBasicInfo = async () => {
  try {
    if (!registrationId.value) {
      // 创建报名
      const res = await createRegistration(form.basic)
      if (res.success && res.data) {
        registrationId.value = res.data.id
        ElMessage.success('创建成功')
        
        // ✅ 新增：创建成功后，更新URL为编辑模式
        router.replace({
          name: 'RegisterForm',
          params: { id: res.data.id }
        })
        
        return true
      }
    } else {
      // 更新基本信息
      const res = await updateRegistration(registrationId.value, form.basic)
      if (res.success) {
        ElMessage.success('保存成功')
        return true
      }
    }
  } catch (error) {
    console.error('保存基本信息失败:', error)
    ElMessage.error('保存基本信息失败')
    return false
  }
}
```

### 为什么使用 `router.replace` 而不是 `router.push`？

| 方法 | 行为 | 适用场景 |
|------|------|----------|
| `router.push` | 添加新的历史记录 | 导航到新页面 |
| `router.replace` | 替换当前历史记录 | 更新当前页面URL |

**选择 `router.replace` 的原因**：
- ✅ 不增加浏览器历史记录（用户点击"返回"会跳到报名列表，而不是 `/new`）
- ✅ URL更新为 `/contestant/register/5`
- ✅ 页面不会重新加载（平滑过渡）
- ✅ 用户体验更好（没有跳转感）

## 📝 总结

### 问题本质
URL状态与应用状态不同步，导致页面刷新后丢失上下文。

### 解决方案
创建报名后立即更新URL，保持URL与应用状态一致。

### 技术要点
- 使用 `router.replace` 更新URL而不增加历史记录
- 确保 `registrationId` 从URL参数正确初始化
- 保证 `loadData()` 能正确加载已保存的数据

### 用户体验提升
- ✅ 数据自动保存，无需手动操作
- ✅ 离开后再编辑，数据不丢失
- ✅ URL更清晰，可直接访问特定报名
- ✅ 浏览器刷新后数据仍然存在
