# 评委分配-已分配任务接口升级完成报告

## 📝 问题描述

### 原有问题

书审和面谈阶段的"查看已分配任务"列表中，除了评委姓名和项目编号外，其他字段都没有值：

**缺失的字段**:
- ❌ 项目名称
- ❌ 医疗机构
- ❌ 组别
- ❌ 分组
- ❌ 评委职称
- ❌ 评委机构
- ❌ 机构等级

### 问题原因

1. **缺少管理端查询接口**
   - 原有的 `AdminReviewController` 没有提供查询已分配任务列表的接口
   - 前端使用的是评委端接口 `/reviews/tasks/stage`

2. **实体序列化问题**
   - `ReviewTask` 实体中的 `registration` 和 `reviewer` 字段使用了 `@JsonIgnore`
   - 导致关联数据无法序列化到响应中

3. **接口返回数据不完整**
   - 原接口只返回基础的任务信息
   - 缺少项目详情和评委详情

## ✅ 后端解决方案

后端已创建新的管理端接口：

### 新接口信息

```
GET /api/admin/reviews/tasks
```

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| competitionId | Long | 是 | 赛事ID |
| stage | String | 是 | 评审阶段：BOOK/INTERVIEW/FINAL |
| status | String | 否 | 任务状态：PENDING/COMPLETED |

**响应数据**（完整字段）:
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "registrationId": 106,
      "projectName": "护理交接班规范化-1",
      "institutionName": "浙江大学医学院附属第二医院",
      "institutionLevel": "三级甲等",
      "groupType": "BASIC",
      "groupCode": "A1",
      "reviewerId": 41,
      "reviewerName": "CommitteeAdmin A",
      "reviewerTitle": "主任",
      "reviewerInstitution": "浙江省卫生健康委员会",
      "status": "PENDING"
    }
  ]
}
```

## 🔧 前端修改内容

### 1. API 定义

**文件**: `src/api/admin.js`

**新增函数**:
```javascript
/**
 * 管理端：查询已分配的评审任务（新接口）
 * @param {Object} params - { competitionId, stage, status }
 * @returns {Promise} 返回完整的任务列表，包含项目信息、评委信息等
 */
export function getAdminReviewTasks(params) {
  return request({
    url: '/admin/reviews/tasks',
    method: 'get',
    params
  })
}
```
