# 等级下拉框问题 - 给后端的问题说明

## 🐛 问题

注册报名页面的机构搜索中，**等级下拉框出现了"三甲"、"二甲"等选项**，这些是医院分级，不应该出现在这里。

---

## 🎯 问题定位（100%后端问题）

### API信息

| 项目 | 值 |
|------|-----|
| **API地址** | `GET /api/institutions/levels` |
| **请求方法** | GET |
| **调用时机** | 前端注册页面初始化时 |
| **前端文件** | `src/components/InstitutionSelector.vue` 第283行 |
| **API定义** | `src/api/institution.js` 第139-145行 |

### 问题数据来源

前端代码：
```javascript
// src/components/InstitutionSelector.vue 第274-284行
onMounted(async () => {
  const [citiesRes, levelsRes] = await Promise.all([
    getCities(),
    getAllLevels()  // ← 调用 GET /api/institutions/levels
  ])
  
  if (levelsRes.success) {
    allLevels.value = levelsRes.data  // ← "三甲"、"二甲"从这里来！
  }
})
```

**结论**：前端只是显示后端返回的数据，没有任何硬编码或数据转换。

---

## 📦 当前返回的错误数据

```json
{
  "success": true,
  "data": [
    "三甲",
    "二甲",
    ...其他医院分级
  ]
}
```

**问题**：这些是医院的三级甲等、二级甲等分类，不是机构的等级分类！

---

## ✅ 正确的返回数据

### 方案1：返回空数组（推荐）

如果机构没有"等级"这个维度：

```json
{
  "success": true,
  "data": []
}
```

### 方案2：返回行政级别

如果确实需要等级筛选：

```json
{
  "success": true,
  "data": [
    "省级",
    "市级", 
    "区县级"
  ]
}
```
