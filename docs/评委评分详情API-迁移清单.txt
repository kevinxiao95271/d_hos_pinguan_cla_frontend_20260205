【🔄 API对比】

旧API (已废弃):
  ❌ GET /api/admin/reviews/feedback
  - 参数: competitionId, stage
  - 返回: 所有项目的评委反馈（需前端筛选）
  - 缺点: 无分项评分、无评委详细信息、无评审时间

新API (推荐):
  ✅ GET /api/registrations/{id}/reviewer-scores?stage={BOOK|INTERVIEW|FINAL}
  - 参数: registrationId (路径), stage (可选)
  - 返回: 指定项目的每位评委详细评分
  - 优势: 
    ✓ 包含7个维度分项评分
    ✓ 包含评委完整信息（姓名、职称、单位、等级）
    ✓ 包含评审时间
    ✓ 包含每位评委的独立评语

汇总API (继续使用):
  ✅ GET /api/registrations/{id}/review-details
  - 用途: 获取平均分和评语汇总
  - 状态: 保留使用

【🎯 新增字段】

每位评委数据包含:
  - reviewerId: 评委ID
  - reviewerName: 评委姓名
  - reviewerTitle: 评委职称
  - reviewerInstitutionId: 评委机构ID
  - reviewerInstitutionName: 评委机构名称
  - reviewerInstitutionLevel: 评委机构等级 ✨
  - scores: { plan, problem, action, success, review, operation, presentation, total }
  - highlight: 亮点评语
  - weakness: 改进建议
  - submittedAt: 评审时间
