# 赛事自动初始化优化

## 问题描述

**用户反馈**：赛事管理者登录后马上就提示"赛事不存在"，需要手动切换赛事才能正常使用，每次登录都需要这样操作，体验不好。

## 问题原因

1. 登录成功后只保存了用户信息和token，没有初始化 `currentCompetitionId`
2. 赛事管理页面依赖 `localStorage.getItem('currentCompetitionId')` 来获取当前赛事
3. 首次登录时 `currentCompetitionId` 为空，导致提示"赛事不存在"

## 解决方案

### 1. 创建赛事工具函数 (`src/utils/competition.js`)

新增工具函数文件，提供统一的赛事ID管理：

```javascript
/**
 * 自动初始化当前赛事（用于赛事管理员）
 * 如果 localStorage 中没有 currentCompetitionId，自动获取第一个赛事并设置
 */
export async function ensureCurrentCompetition()

/**
 * 获取当前赛事ID
 */
export function getCurrentCompetitionId()

/**
 * 设置当前赛事ID
 */
export function setCurrentCompetitionId(competitionId)

/**
 * 清除当前赛事ID
 */
export function clearCurrentCompetitionId()
```

**核心逻辑**：
- 检查 localStorage 中是否已有 `currentCompetitionId`
- 如果没有，自动调用 `/competitions` API 获取赛事列表
- 自动选择第一个赛事作为当前赛事
- 保存到 localStorage

### 2. 优化登录流程 (`src/views/Login.vue`)

在赛事管理者登录成功后，自动初始化当前赛事：

```javascript
if (role === 'COMMITTEE_ADMIN') {
  // 赛事管理者：自动初始化当前赛事
  await initializeCompetitionForAdmin()
  router.push('/committee/book-stage/registration')
}
```

**初始化函数**：
```javascript
const initializeCompetitionForAdmin = async () => {
  console.log('⏳ 正在为赛事管理者初始化赛事...')
  await ensureCurrentCompetition()
}
```

### 3. 统一赛事管理 (`src/views/committee/SwitchCompetition.vue`)

更新切换赛事页面，使用统一的工具函数：

```javascript
// 之前
const currentCompetitionId = ref(parseInt(localStorage.getItem('currentCompetitionId')) || null)
localStorage.setItem('currentCompetitionId', row.id)

// 优化后
import { getCurrentCompetitionId, setCurrentCompetitionId } from '@/utils/competition'
const currentCompetitionId = ref(getCurrentCompetitionId())
setCurrentCompetitionId(row.id)
```

### 4. 优化退出登录 (`src/stores/user.js`)

使用工具函数清除赛事ID：

```javascript
import { clearCurrentCompetitionId } from '@/utils/competition'

logout() {
  this.token = ''
  this.userInfo = null
  localStorage.removeItem('token')
  localStorage.removeItem('userInfo')
  localStorage.removeItem('loginTime')
  localStorage.removeItem('loginTimestamp')
  clearCurrentCompetitionId()  // 使用工具函数
}
```

## 智能初始化逻辑

```javascript
ensureCurrentCompetition() 函数逻辑：

1. 检查是否已有 currentCompetitionId
   ├─ 有 → 直接返回，无需初始化 ✅
   └─ 没有 → 继续下一步

2. 调用 API 获取赛事列表
   ├─ 成功且有数据 → 自动选择第一个赛事 ✅
   ├─ 成功但无数据 → 记录警告，返回 null ⚠️
   └─ 失败 → 记录错误，返回 null ❌

3. 设置 currentCompetitionId 到 localStorage
   └─ 下次无需重复初始化 ✅
```

## 后续优化建议

### 1. 记住用户上次选择的赛事
可以将 currentCompetitionId 与用户ID关联：

```javascript
// 保存：userId_competitionId
localStorage.setItem(`user_${userId}_competition`, competitionId)

// 读取：优先使用用户的上次选择
const lastCompetition = localStorage.getItem(`user_${userId}_competition`)
```

### 2. 赛事列表缓存
可以缓存赛事列表，减少API调用：

```javascript
const CACHE_KEY = 'competitions_cache'
const CACHE_TIME = 5 * 60 * 1000 // 5分钟

// 读取缓存
const cache = JSON.parse(localStorage.getItem(CACHE_KEY))
if (cache && Date.now() - cache.timestamp < CACHE_TIME) {
  return cache.data
}
```

### 3. 赛事变更提醒
如果用户上次登录的赛事已结束或删除：

```javascript
// 检查赛事是否仍然有效
const isValid = await checkCompetitionValid(currentCompetitionId)
if (!isValid) {
  ElMessage.warning('上次选择的赛事已结束，已为您切换到最新赛事')
  await ensureCurrentCompetition()
}
```
