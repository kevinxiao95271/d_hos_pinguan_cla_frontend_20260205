## 🔧 实现步骤模板

### Step 1: 引入 usePagination

```javascript
import { usePagination } from '@/composables/usePagination'
```

### Step 2: 初始化分页

```javascript
// 在 script setup 中
const {
  currentPage,
  pageSize,
  totalCount,
  pageSizes,
  showPagination,
  extractDataList,
  resetPagination,
  getPaginationParams
} = usePagination({
  defaultPageSize: 50,
  pageSizes: [10, 20, 50, 100, 200]
})
```

### Step 3: 修改数据加载函数

```javascript
// 修改前
const loadData = async () => {
  loading.value = true
  try {
    const res = await someApi({ ...filters })
    if (res.success) {
      dataList.value = res.data || []
    }
  } catch (error) {
    console.error('加载失败:', error)
  } finally {
    loading.value = false
  }
}

// 修改后
const loadData = async () => {
  loading.value = true
  try {
    const res = await someApi({ 
      ...filters,
      ...getPaginationParams() // 添加分页参数
    })
    if (res.success) {
      dataList.value = extractDataList(res.data) // 使用 extractDataList 处理
    }
  } catch (error) {
    console.error('加载失败:', error)
  } finally {
    loading.value = false
  }
}
```

### Step 4: 添加分页器组件

```vue
<template>
  <div>
    <!-- 原有表格 -->
    <el-table :data="dataList" v-loading="loading">
      <!-- ... 表格列 ... -->
    </el-table>

    <!-- 添加分页器 -->
    <div v-if="showPagination" class="pagination-container">
      <el-pagination
        v-model:current-page="currentPage"
        v-model:page-size="pageSize"
        :total="totalCount"
        :page-sizes="pageSizes"
        layout="total, sizes, prev, pager, next, jumper"
        @size-change="loadData"
        @current-change="loadData"
      />
    </div>
  </div>
</template>
```

### Step 5: 添加样式

```vue
<style scoped>
.pagination-container {
  margin-top: 20px;
  display: flex;
  justify-content: flex-end;
}
</style>
```

### Step 6: 筛选时重置分页

```javascript
// 在筛选按钮的点击事件中
const handleFilter = () => {
  resetPagination() // 重置到第一页
  loadData()
}
```

## 📝 具体实现示例

### 示例1: 评审任务列表 (src/views/reviewer/Tasks.vue)

```vue
<script setup>
import { ref, onMounted } from 'vue'
import { getMyReviewTasks } from '@/api/review'
import { usePagination } from '@/composables/usePagination'

// 分页
const {
  currentPage,
  pageSize,
  totalCount,
  pageSizes,
  showPagination,
  extractDataList,
  resetPagination,
  getPaginationParams
} = usePagination()

const tasks = ref([])
const loading = ref(false)

// 加载任务列表
const loadTasks = async () => {
  loading.value = true
  try {
    const res = await getMyReviewTasks(getPaginationParams())
    if (res.success) {
      tasks.value = extractDataList(res.data)
    }
  } catch (error) {
    console.error('加载任务失败:', error)
  } finally {
    loading.value = false
  }
}

onMounted(() => {
  loadTasks()
})
</script>

<template>
  <div class="tasks-page">
    <el-table :data="tasks" v-loading="loading">
      <!-- ... 表格列 ... -->
    </el-table>

    <!-- 分页器 -->
    <div v-if="showPagination" class="pagination-container">
      <el-pagination
        v-model:current-page="currentPage"
        v-model:page-size="pageSize"
        :total="totalCount"
        :page-sizes="pageSizes"
        layout="total, sizes, prev, pager, next, jumper"
        @size-change="loadTasks"
        @current-change="loadTasks"
      />
    </div>
  </div>
</template>

<style scoped>
.pagination-container {
  margin-top: 20px;
  display: flex;
  justify-content: flex-end;
}
</style>
```

## ⚠️ 注意事项

### 1. API参数传递
确保将分页参数正确传递给API：
```javascript
// ✅ 正确
const res = await api({ 
  competitionId: 21,
  ...getPaginationParams() 
})

// ❌ 错误（忘记传分页参数）
const res = await api({ competitionId: 21 })
```

### 2. 数据提取
必须使用 `extractDataList` 处理返回数据：
```javascript
// ✅ 正确
tasks.value = extractDataList(res.data)

// ❌ 错误（直接赋值）
tasks.value = res.data
```

### 3. 筛选重置
筛选或搜索时需要重置到第一页：
```javascript
const handleSearch = () => {
  resetPagination() // 重要！
  loadData()
}
```

### 4. 分页器显示
只在有数据时显示分页器：
```vue
<div v-if="showPagination" class="pagination-container">
  <el-pagination ... />
</div>
```

## 📊 分页器配置

### 默认配置
```javascript
{
  defaultPageSize: 50,
  pageSizes: [10, 20, 50, 100, 200]
}
```

### 布局选项
```
layout="total, sizes, prev, pager, next, jumper"
```

说明：
- `total`: 总条数
- `sizes`: 每页数量选择器
- `prev`: 上一页按钮
- `pager`: 页码
- `next`: 下一页按钮
- `jumper`: 跳转输入框
