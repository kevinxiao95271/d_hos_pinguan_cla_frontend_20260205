## ⚠️ 已知问题

### 1. 组别统计显示为0

**原因**:
- 后端 `/api/admin/stats/summary` 暂未返回 `basicCount`、`comprehensiveCount`、`advancedCount` 字段

**当前处理**:
```javascript
stats.basicGroup = summaryData.basicCount || 0  // 显示0
stats.comprehensiveGroup = summaryData.comprehensiveCount || 0
stats.advancedGroup = summaryData.advancedCount || 0
```

**解决方案**（二选一）:
1. **后端添加字段**（推荐）:
   - 在 `StatsSummaryResponse` 中添加 `basicCount`、`comprehensiveCount`、`advancedCount` 字段
   - 后端直接统计各组别的报名数量
   
2. **前端恢复计算逻辑**:
   - 如果后端无法提供，前端可以单独调用 `filterRegistrations` 获取详细数据
   - 仅用于计算组别统计，其他统计仍使用 `getStatsSummary`

### 2. 评分雷达图可能全为0

**原因**:
- 如果最新赛事还没有评分数据，`avgPlan`、`avgProblem` 等字段可能都是0

**当前处理**:
```javascript
const avgScores = [
  summaryData.avgPlan || 0,  // 默认为0
  // ...
]
```

**优化建议**:
- 如果所有评分都是0，可以在雷达图中显示"暂无评分数据"提示
- 或者隐藏雷达图，等有评分数据后再显示
