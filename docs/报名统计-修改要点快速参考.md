# 报名统计-修改要点快速参考

## 🔑 关键修改

### 1. API调用方式

**❌ 旧方式**:
```javascript
const res = await filterRegistrations({ competitionId: 21 })
// 返回: { data: [项目1, 项目2, ...] }
```

**✅ 新方式**:
```javascript
const res = await getStatsSummary()  // 无需参数！
// 返回: { data: { registrationCount: 45, regionCounts: {...}, ... } }
```

### 2. 数据字段映射

| 前端需求 | API字段 | 类型 | 说明 |
|---------|--------|------|------|
| 总报名数 | `registrationCount` | Number | ✅ 可用 |
| 地区分布 | `regionCounts` | Object | ✅ 可用，如: `{"杭州":17, "舟山":15}` |
| 主题类型 | `subjectTypeCounts` | Object | ✅ 可用，如: `{"医疗安全":15}` |
| 计划平均分 | `avgPlan` | Number | ✅ 可用，0-20分 |
| 问题平均分 | `avgProblem` | Number | ✅ 可用，0-20分 |
| 行动平均分 | `avgAction` | Number | ✅ 可用，0-20分 |
| 成功平均分 | `avgSuccess` | Number | ✅ 可用，0-20分 |
| 回顾平均分 | `avgReview` | Number | ✅ 可用，0-20分 |
| 运作平均分 | `avgOperation` | Number | ✅ 可用，0-20分 |
| 展示平均分 | `avgPresentation` | Number | ✅ 可用，0-20分 |
| 基层组数量 | `basicCount` | Number | ⚠️ 暂缺，显示0 |
| 综合组数量 | `comprehensiveCount` | Number | ⚠️ 暂缺，显示0 |
| 进阶组数量 | `advancedCount` | Number | ⚠️ 暂缺，显示0 |

### 3. 图表数据来源

| 图表 | 旧数据来源 | 新数据来源 |
|-----|-----------|-----------|
| 地区分布饼图 | ❌ 前端关键词匹配 | ✅ `summaryData.regionCounts` |
| 主题类型饼图 | ❌ 前端遍历计算 | ✅ `summaryData.subjectTypeCounts` |
| 组别分布饼图 | ❌ 前端filter计算 | ⚠️ 后端暂缺字段 |
| 评分雷达图 | ❌ 无 | ✅ `summaryData.avgPlan`等7个字段（新增） |
| 品管工具图 | ❌ 前端遍历计算 | ❌ 已移除（后端无此字段） |

## 📝 代码对比

### loadData 函数

**旧代码**:
```javascript
const competitionId = localStorage.getItem('currentCompetitionId') || 21
const res = await filterRegistrations({ competitionId })
const registrations = res.data
stats.totalRegistrations = registrations.length
stats.basicGroup = registrations.filter(r => r.groupType === 'BASIC').length
```

**新代码**:
```javascript
const res = await getStatsSummary()  // 无需参数
const summaryData = res.data
stats.totalRegistrations = summaryData.registrationCount
stats.basicGroup = summaryData.basicCount || 0  // 暂时为0
```

### 地区分布图表

**旧代码**:
```javascript
// ❌ 前端自行识别地区
const cityKeywords = ['杭州', '宁波', ...]
registrations.forEach(r => {
  for (const city of cityKeywords) {
    if (r.institutionName.includes(city)) {
      regionStats[city]++
    }
  }
})
```

**新代码**:
```javascript
// ✅ 直接使用后端数据
const regionCounts = summaryData.regionCounts || {}
// { "杭州": 17, "舟山": 15, ... }
const regionData = Object.entries(regionCounts)
  .map(([name, value]) => ({ name, value }))
```

### 评分雷达图（新增）

```javascript
// ✅ 7个维度的平均分
const avgScores = [

// 雷达图配置

```

## ⚠️ 注意事项

### 1. 接口行为

- ✅ **无需参数**: 接口自动返回最新赛事（ID最大）
- ✅ **赛事信息**: 返回 `competitionId` 和 `competitionName` 方便确认
- ⚠️ **指定赛事**: 当前不支持，如需要请联系后端添加参数

### 2. 数据准确性

- ✅ **地区数据**: 后端已修正，杭州17条、舟山15条等准确
- ✅ **主题类型**: 后端统计，无需前端关键词匹配
- ⚠️ **组别统计**: 后端暂未返回，前端显示0

### 3. 空数据处理

```javascript
// ✅ 安全的空数据处理
const regionCounts = summaryData.regionCounts || {}
const subjectTypeCounts = summaryData.subjectTypeCounts || {}

if (Object.keys(regionCounts).length === 0) {
  // 显示"暂无数据"
}
```
