## 🔌 API接口

### 1. 获取我的报名列表

```
GET /api/registrations/my
Authorization: Bearer {token}
```

**响应数据结构:**
```json
{
  "success": true,
  "data": [
    {
      "id": 116,
      "projectName": "门诊预约体验提升-11",
      "groupType": "BASIC",
      "groupCode": "A1",
      "status": "APPROVED",
      "submittedAt": "2026-02-05T10:30:00",
      "createdAt": "2026-02-04T15:20:00"
    }
  ]
}
```

**前端使用:**
```javascript
// src/views/contestant/MyRegistrations.vue
import { getMyRegistrations } from '@/api/registration'

const loadData = async () => {
  const res = await getMyRegistrations()
  if (res.success) {
    registrations.value = res.data || []
  }
}
```

```json
    },

```

**⚠️ 关键点:**
- ✅ 使用 `data.registration.projectName`，不是 `data.projectName`
- ✅ 使用 `data.projectSummary`，不是 `data.summary`
- ✅ `members` 可能为空数组（草稿状态）
- ✅ `activityInfo` 可能为 `null`（未填写）
- ✅ `projectSummary` 可能为 `null`（未填写）

**前端使用:**
```javascript
// src/views/contestant/ReviewResults.vue
import { getRegistration } from '@/api/registration'

const loadData = async () => {
  const res = await getRegistration(registrationId.value)
  if (res.success && res.data) {
    const data = res.data
    
    // ✅ 从 registration 对象提取基本信息
    detail.projectName = data.registration?.projectName || ''
    detail.groupType = data.registration?.groupType || ''
    detail.status = data.registration?.status || ''
    
    // ✅ 成员列表
    detail.members = data.members || []
    
    // ✅ 活动说明
    detail.activityInfo = data.activityInfo
    
    // ✅ 项目总结
    detail.summary = data.projectSummary  // 注意字段名
  }
}
```

## 📄 页面开发指南

### 页面1: 我的报名列表 (MyRegistrations.vue)

**路由:** `/contestant/my-registrations`

**功能:**
- 显示我的所有报名
- 每个报名显示：项目名称、组别、状态、提交时间
- 操作按钮：
  - 草稿状态 → "继续编辑"按钮
  - 已提交 → "查看详情"按钮
  - 已审核通过 → "查看评审结果"按钮

**数据结构:**
```javascript
const registrations = ref([])

// 状态映射
const getStatusText = (status) => {
  const map = {
    'DRAFT': '草稿',
    'SUBMITTED': '已提交',
    'APPROVED': '已通过',
    'REJECTED': '已驳回'
  }
  return map[status] || status
}
```

### 页面2: 报名表单 (RegisterForm.vue)

**路由:** `/contestant/register/:competitionId`

**功能:**
- 多步骤表单（跑马灯导航）
  1. 报名表（项目名称、成员、辅导员）
  2. 活动说明（主题、工具、改善领域）
  3. 项目总结（计划、问题、实施、成果、总结）
  4. 提交材料（文件上传）

**API调用顺序:**
```javascript
// 1. 创建报名（获取ID）
const createRes = await createRegistration({
  competitionId: competitionId.value,
  institutionId: institutionId.value,
  projectName: form.projectName,
  groupType: form.groupType
})
const registrationId = createRes.data.id

// 2. 更新成员
await updateRegistrationMembers(registrationId, {
  members: form.members  // Array<{name, title, department, role}>
})

// 3. 更新活动说明
await updateRegistrationActivity(registrationId, {
  theme: form.theme,
  keywords: form.keywords,
  subjectTypeCode: form.subjectTypeCode,
  methodCode: form.methodCode,
  // ...
})

// 4. 更新项目总结
await updateRegistrationSummary(registrationId, {
  plan: form.plan,
  problemAnalysis: form.problemAnalysis,
  implementation: form.implementation,
  result: form.result,
  review: form.review
})

// 5. 上传材料（可选）
await uploadRegistrationMaterial(registrationId, file, 'APPLICATION_FORM')

// 6. 提交审核
await submitRegistration(registrationId)
```

**注意事项:**
- ✅ 支持草稿保存（每步完成后自动保存）
- ✅ 已提交的报名不允许修改
- ✅ 表单验证（必填项、格式检查）

## 🎯 数据字段对照表

### 报名状态 (status)

| 值 | 中文 | 说明 |
|----|------|------|
| `DRAFT` | 草稿 | 未提交 |
| `SUBMITTED` | 已提交 | 等待审核 |
| `APPROVED` | 已通过 | 审核通过 |
| `REJECTED` | 已驳回 | 审核未通过 |

### 竞赛组别 (groupType)

| 值 | 中文 |
|----|------|
| `BASIC` | 基层组 |
| `COMPREHENSIVE` | 综合组 |
| `ADVANCED` | 进阶组 |

### 成员角色 (role)

| 值 | 中文 |
|----|------|
| `MENTOR` | 辅导员 |
| `PARTICIPANT` | 参与人员 |

### 评审阶段

| 值 | 中文 |
|----|------|
| `BOOK` | 书审 |
| `INTERVIEW` | 面谈 |
| `FINAL` | 决赛 |
