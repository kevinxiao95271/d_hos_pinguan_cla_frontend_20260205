# 导航结构说明

## 赛事管理端（组委会/运维）导航重构

### 新的导航结构

#### 左侧导航菜单

```
├─ 赛事管理 (默认展开)
│  ├─ 报名统计
│  ├─ 书审阶段
│  ├─ 面谈阶段
│  └─ 决赛阶段
├─ 创建赛事
└─ 切换赛事
```

### 详细说明

#### 1. 赛事管理（主菜单）
- **默认路由**: 登录后自动跳转到 `/committee/statistics`（报名统计）
- **子菜单**:
  - **报名统计**: `/committee/statistics`
    - 展示赛事总体统计数据
    - 包含图表展示（竞赛组别分布、品管工具分布、主题类型分布）
    - 统计卡片（总报名数、基层组、综合组、进阶组）
  
  - **书审阶段**: `/committee/book-stage`
    - Tab 1: 报名与分组
      - 报名列表筛选（机构、组别、分组、项目名、品管工具）
      - 自动分组功能
      - 批量分类功能
      - 单个变更分组功能
    - Tab 2: 评委分配
    - Tab 3: 书审得分
    - Tab 4: 专家意见反馈
  
  - **面谈阶段**: `/committee/interview-stage`
    - Tab 1: 面谈分组
    - Tab 2: 评委分配
    - Tab 3: 面谈得分
    - Tab 4: 入围管理
  
  - **决赛阶段**: `/committee/final-stage`
    - Tab 1: 决赛分组
    - Tab 2: 评委分配
    - Tab 3: 现场打分
    - Tab 4: 最终排名

#### 2. 创建赛事
- **路由**: `/committee/create-competition`
- **功能**: 创建新的赛事
- **位置**: 左侧导航最后

#### 3. 切换赛事
- **路由**: `/committee/switch-competition`
- **功能**: 
  - 展示所有赛事列表
  - 查看各赛事的当前阶段
  - 快速切换要管理的赛事
  - 切换后自动跳转到该赛事的报名统计页面
- **位置**: 左侧导航最后

### 导航样式

#### 配色方案（经典蓝色）
- **背景色**: `#001529`（深蓝黑）
- **激活状态**: `#1890ff`（经典蓝）
- **文字颜色**: 白色
- **字体**: 加粗显示
- **子菜单背景**: `#000c17`（更深的蓝黑）

#### 交互效果
- 鼠标悬停：背景变为蓝色 `#1890ff`
- 当前激活项：蓝色背景 + 白色加粗字体
- 子菜单：略深背景以区分层级

### 技术实现

#### 文件修改清单
1. `src/layouts/MainLayout.vue`
   - 更新菜单结构
   - 添加经典蓝色样式

2. `src/router/index.js`
   - 重构路由结构
   - 设置默认路由为 `/committee/statistics`

3. 新增视图文件
   - `src/views/committee/Statistics.vue` - 报名统计
   - `src/views/committee/BookStage.vue` - 书审阶段
   - `src/views/committee/InterviewStage.vue` - 面谈阶段
   - `src/views/committee/FinalStage.vue` - 决赛阶段
   - `src/views/committee/SwitchCompetition.vue` - 切换赛事

4. 更新登录跳转
   - `src/views/Login.vue` - 组委会登录后跳转到统计页面
   - `src/views/Dashboard.vue` - 同步更新跳转逻辑

### 依赖包

- **echarts**: `^5.6.0` - 用于统计图表展示
- **dayjs**: `^1.11.19` - 日期格式化

### 使用说明

1. **登录后**：组委会和运维角色自动进入"报名统计"页面
2. **导航切换**：点击左侧菜单可切换到不同的管理阶段
3. **赛事切换**：通过"切换赛事"菜单选择要管理的赛事
4. **创建赛事**：通过"创建赛事"菜单创建新的赛事
