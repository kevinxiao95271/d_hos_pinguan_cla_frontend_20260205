**关键代码**:
```javascript
// 1. 引入
import { usePagination } from '@/composables/usePagination'

// 2. 初始化
const {
  currentPage, pageSize, totalCount, pageSizes,
  showPagination, extractDataList, resetPagination, getPaginationParams
} = usePagination({ defaultPageSize: 50 })

// 3. 数据加载
const loadData = async () => {
  const res = await getMyReviewTasks(getPaginationParams())
  if (res.success) {
    tasks.value = extractDataList(res.data)
  }
}

// 4. 重置筛选
const resetFilters = () => {
  filters.stage = ''
  filters.status = ''
  resetPagination()
  loadData()
}
```

```vue
<!-- 5. 分页器 -->
<div v-if="showPagination" class="pagination-container">
  <el-pagination
    v-model:current-page="currentPage"
    v-model:page-size="pageSize"
    :total="totalCount"
    :page-sizes="pageSizes"
    layout="total, sizes, prev, pager, next, jumper"
    @size-change="loadData"
    @current-change="loadData"
  />
</div>
```

## ⚠️ 重要注意事项

### 1. 向后兼容
- 所有修改保持向后兼容
- 不传分页参数时，API返回全部数据
- `extractDataList` 会自动处理数组和分页对象两种格式

### 2. 多列表页面
- 每个列表需要独立的分页实例
- 使用不同的变量名区分（如 `regPage` / `revPage`）

### 3. 筛选重置
- 筛选或搜索时必须调用 `resetPagination()`
- 否则可能停留在空页面

### 4. 数据提取
- 必须使用 `extractDataList(res.data)` 处理返回数据
- 不能直接赋值 `dataList.value = res.data`
