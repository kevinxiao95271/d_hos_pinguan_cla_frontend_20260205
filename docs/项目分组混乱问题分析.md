## 问题根源（已确认）

### 🚨 后端API严重Bug

**接口：** `POST /api/admin/registrations/auto-group`

**测试数据：**
```
请求：对基层组(BASIC)执行自动分组
{
  "competitionId": 1,
  "groupType": "BASIC",
  "groupPrefix": "A",
  "groupSize": 25
}

响应：影响了123个项目，包括：
  - BASIC（基层组）: 43人 ✅
  - COMPREHENSIVE（综合组）: 38人 ❌ 不应该被影响
  - ADVANCED（进阶组）: 42人 ❌ 不应该被影响
```

**问题确认：** 后端自动分组API完全忽略了`groupType`参数：
1. ❌ 后端忽略了`groupType`筛选条件
2. ❌ 对该赛事下的**所有报名项目**（不管什么组别）进行分组
3. ❌ 使用请求中的`groupPrefix`给所有项目（包括其他组别）分配分组编号

**实际影响示例：**

当对"基层组"执行自动分组（`groupType=BASIC, groupPrefix=A`）时：
```
响应中包含非基层组的项目：
  - ID=4,  groupType=COMPREHENSIVE, groupCode=A1  ❌ 综合组被分配到A组
  - ID=8,  groupType=ADVANCED,      groupCode=A1  ❌ 进阶组被分配到A组
  - ID=9,  groupType=COMPREHENSIVE, groupCode=A1  ❌ 综合组被分配到A组
  - ID=10, groupType=COMPREHENSIVE, groupCode=A1  ❌ 综合组被分配到A组
  - ID=11, groupType=COMPREHENSIVE, groupCode=A1  ❌ 综合组被分配到A组
```

**这就是为什么用户看到"基层组都落到了B1 B2"或"C组"的原因！**
- 如果最后一次操作是对综合组自动分组，所有项目都会在B组
- 如果最后一次操作是对进阶组自动分组，所有项目都会在C组

## 修复方案

### 方案A：修改后端API（推荐）

后端自动分组API应该：
```java
// 伪代码
public void autoGroup(Long competitionId, String groupType, String groupPrefix, Integer groupSize) {
    // 1. 筛选条件：只获取指定competitionId AND groupType的报名记录
    List<Registration> registrations = registrationRepo.findByCompetitionIdAndGroupType(
        competitionId, 
        groupType  // ⚠️ 关键：只处理指定组别的项目
    );
    
    // 2. 对这些项目进行自动分组
    int groupNumber = 1;
    for (int i = 0; i < registrations.size(); i++) {
        String groupCode = groupPrefix + groupNumber;
        registrations.get(i).setGroupCode(groupCode);
        
        if ((i + 1) % groupSize == 0) {
            groupNumber++;
        }
    }
    
    // 3. 保存
    registrationRepo.saveAll(registrations);
}
```

**关键点：** 后端必须根据`groupType`参数筛选项目，而不是处理所有项目！

## 结论

**这是后端API的问题！**

❌ **后端问题：** `POST /api/admin/registrations/auto-group` API没有根据`groupType`参数筛选项目，导致：
- 执行"基层组自动分组"时，所有组别（基层组、综合组、进阶组）的项目都被分配到A组
- 执行"进阶组自动分组"时，所有组别的项目都被分配到C组
- 这导致了分组混乱

✅ **前端代码：** 经检查，前端正确传递了所有必需参数（`competitionId`, `groupType`, `groupPrefix`, `groupSize`）

**建议：** 需要后端开发人员修复自动分组API，确保只对指定`groupType`的项目进行分组操作。
