所有API都使用以下响应格式：

```json

  "success": true,
  "data": [...],
  "message": null
}
```

### ⚠️ 文档需要更新

原文档中描述的格式：
```json

  "code": 200,
  "message": "success",
  "data": [...]
}
```

- 实际使用 `success: true/false`，而不是 `code: 200`
- message字段通常为null，不是"success"

**影响：** 前端代码已按 `success` 字段实现，与实际API一致，无需调整。
