# 变更分组逻辑说明 📋

## 🎯 业务规则

### 核心原则

**竞赛组别由报名时确定，变更分组只能在同一组别内调整分组编号。**

### 示例说明

| 操作 | 允许 | 说明 |
|------|------|------|
| 基层组 A1 → A2 | ✅ | 同组别内调整 |
| 基层组 A1 → A3 | ✅ | 同组别内调整 |
| 综合组 B1 → B2 | ✅ | 同组别内调整 |
| **基层组 A1 → 综合组 B1** | ❌ | **不能跨组别** |
| **综合组 B1 → 进阶组 C1** | ❌ | **不能跨组别** |

### 组别与分组对应关系

```
基层组 (BASIC)
├── A1, A2, A3, A4, A5...
└── 只能在 A 系列内调整

综合组 (COMPREHENSIVE)
├── B1, B2, B3, B4, B5...
└── 只能在 B 系列内调整

进阶组 (ADVANCED)
├── C1, C2, C3, C4, C5...
└── 只能在 C 系列内调整
```

## 📝 功能实现

### 单个项目变更

**操作流程:**
```
1. 点击列表中某项目的"变更分组"按钮
2. 弹出对话框
   - 竞赛组别: 基层组 (灰色标签，不可更改)
   - 当前分组: A1 (灰色标签)
   - 调整到: [下拉选择] A2, A3, A4...
3. 选择新的分组（如 A3）
4. 点击"确定"
5. ✅ 项目分组从 A1 变更为 A3
```

**约束:**
- ✅ 下拉框只显示同组别的分组（A1-A10）
- ✅ 当前分组被禁用（不能选择）
- ✅ 未选择新分组时"确定"按钮禁用

### 批量变更

**操作流程:**
```
1. 勾选多个项目（如 3 个基层组项目）
2. 点击"批量分类"按钮
3. 弹出对话框
   - 竞赛组别: 基层组 (所有选中项目的组别)
   - 当前分组: 多个
   - 调整到: [下拉选择] A1, A2, A3...
4. 选择新的分组（如 A5）
5. 点击"确定"
6. ✅ 所有选中项目的分组都变更为 A5
```

**约束:**
- ✅ 检查所选项目是否同一组别
- ❌ 如果选中了不同组别的项目，提示错误
- ✅ 批量变更时，所有项目统一调整到选定分组

**单个变更:**
```javascript
const changeGroup = (row) => {
  changeGroupForm.groupType = row.groupType       // 固定，不可更改

}
```

**批量变更:**
```javascript
const batchClassify = () => {
  // 检查是否同一组别
  const groupTypes = new Set(selectedRegistrations.map(r => r.groupType))
  if (groupTypes.size > 1) {
    ElMessage.warning('批量分类只能对同一竞赛组别的项目进行操作')
    return
  }
  
  // 继续批量变更
  changeGroupForm.groupType = firstItem.groupType
  changeGroupForm.currentGroupCode = '多个'
}
```

## ⚠️ 错误提示

### 批量选择不同组别

```
操作: 选中 2 个基层组项目 + 1 个综合组项目
点击: "批量分类"
提示: ⚠️  批量分类只能对同一竞赛组别的项目进行操作
```

### 未选择新分组

```
操作: 打开变更分组对话框
当前: 当前分组 A1，未选择新分组
状态: "确定"按钮禁用（灰色）
```

### 选择相同分组

```
操作: 当前分组 A1，选择新分组 A1
状态: "确定"按钮禁用
提示: A1 选项被禁用（显示为灰色）
```
