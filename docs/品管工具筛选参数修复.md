## 📝 API 说明

### 后端接口

```
GET /api/admin/registrations/filter
```

### 支持的参数

| 参数 | 类型 | 说明 | 示例 |
|-----|------|------|------|
| `competitionId` | Integer | 赛事ID（必需） | `21` |
| `institutionName` | String | 医疗机构名称（模糊匹配） | `"浙江大学"` |
| `groupType` | String | 竞赛组别 | `"BASIC"` |
| `groupCode` | String | 分组 | `"A1"` |
| `projectName` | String | 项目名称（模糊匹配） | `"护理"` |
| **`methodLabel`** | **String** | **品管工具（中文标签）** | **`"品管圈-课题达成"`** |

### 注意事项

⚠️ **重要**: 
- 后端API使用 `methodLabel`（中文标签），不是 `methodCode`（代码值）
- 前端下拉框应该绑定 `label` 值，不是 `code` 值
- 筛选时直接传递用户选择的中文名称

## 💡 技术要点

### 1. 下拉框数据绑定

```javascript
// 字典数据结构
{
  code: "method_1",        // 内部代码
  label: "品管圈-课题达成"  // 显示标签
}

// ❌ 错误：绑定 code
<el-option :value="item.code" />
// 结果：filters.methodCode = "method_1"
// 问题：后端不识别这个 code

// ✅ 正确：绑定 label
<el-option :value="item.label" />
// 结果：filters.methodLabel = "品管圈-课题达成"
// 结果：后端正确识别并返回数据
```

### 2. 参数命名一致性

**最佳实践**:
- 前端参数名 = 后端参数名
- 前端传递的值 = 后端期望的值类型

**本次修复**:
```javascript
// 前端
filters.methodLabel = "品管圈-课题达成"

// API请求
GET /api/admin/registrations/filter?methodLabel=品管圈-课题达成

// 后端
@RequestParam String methodLabel
```

### 3. 字典数据的两种用法

**用法1: 用于显示（使用 label）**
```vue
<el-table-column prop="methodLabel" label="品管工具" />
```

**用法2: 用于筛选（本次修复：使用 label 而不是 code）**
```vue
<el-select v-model="filters.methodLabel">
  <el-option :value="item.label" />  <!-- ✅ 使用 label -->
</el-select>
```
