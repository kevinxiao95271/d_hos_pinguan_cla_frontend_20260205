# 评审任务API - 500错误报告

## 🐛 问题描述

查看已分配任务功能报错，书审和面谈阶段都无法加载任务列表。

## 📊 错误详情

### API端点
```
GET /api/admin/reviews/tasks
```

### 请求参数
```javascript
{
  competitionId: 21,
  stage: 'BOOK'        // 或 'INTERVIEW'
}
```

### 错误信息
```json
{
  "timestamp": "2026-02-11T13:07:52.061+00:00",
  "status": 500,
  "error": "Internal Server Error",
  "path": "/api/admin/reviews/tasks"
}
```

### HTTP状态码
- ❌ **500 Internal Server Error**

## 🔧 可能的原因

### 1. 数据库查询问题
- SQL语句错误
- 表或字段不存在
- 数据类型不匹配

### 2. 空指针异常
- 某个对象为null但未做判断
- 关联数据缺失（如评委信息、报名信息）

### 3. 枚举类型问题
- `stage` 参数值可能与后端枚举不匹配
- 后端期望的值：`BOOK_REVIEW`、`INTERVIEW`？

### 4. 权限验证问题
- Token解析异常
- 权限检查逻辑错误

## 🔄 前端错误处理

前端已有基本的错误处理：

```javascript
try {
  const res = await getReviewTasks({ competitionId, stage })
  if (res.success && res.data) {
    // 成功处理
  }
} catch (error) {
  console.error('❌ 加载已分配任务失败:', error)
  ElMessage.error('加载任务失败: ' + (error.message || '服务器错误'))
}
```

但由于是500错误，前端无法自行修复，必须由后端解决。
