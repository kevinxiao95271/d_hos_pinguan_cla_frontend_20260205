# 地区选择功能升级 - 完整测试指南

## 📋 升级摘要

**升级时间**: 2026-02-08  
**影响组件**: InstitutionSelector.vue  
**核心改进**: 从区县级别（90+）升级为市级别（11个）+ 区县二级筛选

## 🎯 升级亮点

1. **11个城市快速选择** - 从90+区县降为11个市，效率提升8倍
2. **智能两级筛选** - 先选城市（6千家），再选区县（1千家）
3. **性能优化** - 市级别搜索响应时间大幅缩短
4. **向后兼容** - 原有区县级别搜索仍然有效

## 🔧 修改文件

### 1. API层（src/api/institution.js）
新增两个公开API函数：
```javascript
export function getCities()           // 获取11个城市
export function getDistricts(city)     // 获取指定城市的区县
```

### 2. 组件层（src/components/InstitutionSelector.vue）
全面升级：
- ✅ 模板：快速城市选择 + 城市/区县两级筛选器
- ✅ 逻辑：城市变更 → 加载区县 → 搜索机构
- ✅ 样式：city-selection替代hot-regions

### 3. 测试脚本（scripts/test_city_apis.py）
验证后端新增的城市级别API。

## 🐛 常见问题排查

### 问题1: 城市列表不显示

**可能原因**:
- 后端服务未启动
- API地址配置错误
- 网络请求被拦截

**排查方法**:
1. 检查浏览器控制台是否有错误
2. 检查Network标签，是否有失败的请求
3. 手动访问 `http://localhost:6031/api/institutions/cities` 验证后端

### 问题2: 区县列表加载失败

**可能原因**:
- 城市参数传递错误
- 后端区县数据不完整

**排查方法**:
1. 检查浏览器控制台的请求URL
2. 确认city参数是否正确（如"杭州市"，不是"杭州"）
3. 手动访问 `http://localhost:6031/api/institutions/districts?city=杭州市`

### 问题3: 搜索结果数量不符

**可能原因**:
- region参数逻辑错误
- 后端数据不同步

**排查方法**:
1. 检查InstitutionSelector.vue中的loadInstitutions函数
2. 确认region参数优先级: district > city
3. 对比后端API文档中的数据分布

### 问题4: 分页器显示异常

**可能原因**:
- total未正确设置
- 后端返回的totalElements字段缺失

**排查方法**:
1. 检查API响应中的data.totalElements字段
2. 检查组件中的total.value是否正确赋值
3. 检查el-pagination的配置
