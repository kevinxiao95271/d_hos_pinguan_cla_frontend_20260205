## 🔍 五、补充说明

### 1. 机构等级的可能值
根据中国医院分级标准，机构等级通常包括：
- 三级甲等、三级乙等、三级丙等
- 二级甲等、二级乙等、二级丙等
- 一级甲等、一级乙等、一级丙等
- 未定级

建议：
- 后端存储格式：字符串，如 "三级甲等"
- 前端显示：直接显示，可添加颜色区分
- 筛选支持：支持按等级筛选

### 2. 数据迁移
- 现有机构数据可能没有 level 字段
- 建议后端允许 level 为空，前端显示 "未填写" 或 "-"
- 后续可通过机构管理页面补充

### 3. 同机构回避逻辑增强
目前评委分配时使用 `institutionId` 判断是否同机构。  
添加 `institutionLevel` 字段后，可以在UI上更清晰地展示：
```
评委：李明华 - 浙江大学医学院附属第二医院（三级甲等）
项目：护理交接班规范化-1 - 浙江大学医学院附属第一医院（三级甲等）
```
