## 问题分析

### 1. 前端当前实现

#### API定义 (`src/api/material.js` 第8-17行)

```javascript
export function uploadMaterial(registrationId, formData) {
  return request({
    url: `/materials/upload/${registrationId}`,  // ❌ 错误的路径
    method: 'post',
    data: formData,
    headers: {
      'Content-Type': 'multipart/form-data'
    }
  })
}
```

**实际调用路径**: `POST /api/materials/upload/131`

**问题**:
- 前端使用的路径：`/materials/upload/{registrationId}`
- 这个路径后端不存在（返回404）

#### 调用代码 (`src/views/contestant/RegisterForm.vue` 第935-958行)

```javascript
// 上传报名表
if (form.materials.registrationForm.length > 0 && form.materials.registrationForm[0].raw) {
  const formData = new FormData()
  formData.append('file', form.materials.registrationForm[0].raw)
  await uploadMaterial(registrationId.value, formData)  // ❌ 缺少materialType
  console.log('✅ 报名表上传成功')
}

// 上传成果报告书
if (form.materials.report.length > 0 && form.materials.report[0].raw) {
  const formData = new FormData()
  formData.append('file', form.materials.report[0].raw)
  await uploadMaterial(registrationId.value, formData)  // ❌ 缺少materialType
  console.log('✅ 成果报告书上传成功')
}

// 上传佐证材料
for (const evidence of form.materials.evidence) {
  if (evidence.raw) {
    const formData = new FormData()
    formData.append('file', evidence.raw)
    await uploadMaterial(registrationId.value, formData)  // ❌ 缺少materialType
  }
}
```

**问题**:
- 只上传了 `file`
- 缺少 `materialType` 参数

---

### 2. 文档中的正确定义

#### API文档 (`docs/FINAL_API_GUIDE.md` 第406-429行)

```javascript
// 请求
POST /api/registrations/{id}/materials
Headers: {
  Authorization: Bearer {token},
  Content-Type: multipart/form-data
}
FormData: {
  materialType: "REGISTRATION_FORM",  // REGISTRATION_FORM, REPORT, EVIDENCE
  file: <File>
}

// 响应
{
  "success": true,
  "data": {
    "materialId": 567,
    "fileName": "报名表.pdf",
    "fileUrl": "https://..."
  }
}
```

**正确路径**: `POST /api/registrations/{id}/materials`

**必需参数**:
- `materialType`: 材料类型枚举
  - `REGISTRATION_FORM` - 报名表
  - `REPORT` - 成果报告书
  - `EVIDENCE` - 佐证材料
- `file`: 文件对象

---

### 3. 路径测试结果

| 路径 | 状态码 | 结论 |
|---|---|---|
| `/api/materials/upload/131` | 404 | ❌ 不存在（前端当前使用） |
| `/api/registrations/131/materials` | 400 | ⚠️ 存在，但请求格式错误 |
| `/api/registrations/131/materials/upload` | 404 | ❌ 不存在 |
| `/api/materials/131` | 405 | ❌ 方法不允许 |
| `/api/materials/131/upload` | 404 | ❌ 不存在 |

**结论**: 
- ✅ 正确路径是 `/api/registrations/{id}/materials`
- ⚠️ 当前返回400可能是因为：
  1. 缺少 `materialType` 参数
  2. 参数格式不对
  3. 报名状态不允许上传（DRAFT状态）

## 修复方案

### 方案1: 修改 API 定义和调用代码（推荐）

#### 1. 修改 `src/api/material.js`

```javascript
// 修改前
export function uploadMaterial(registrationId, formData) {
  return request({
    url: `/materials/upload/${registrationId}`,
    method: 'post',
    data: formData,
    headers: {
      'Content-Type': 'multipart/form-data'
    }
  })
}

// 修改后
export function uploadMaterial(registrationId, materialType, file) {
  const formData = new FormData()
  formData.append('file', file)
  formData.append('materialType', materialType)
  
  return request({
    url: `/registrations/${registrationId}/materials`,
    method: 'post',
    data: formData,
    headers: {
      'Content-Type': 'multipart/form-data'
    }
  })
}
```

#### 2. 修改 `src/views/contestant/RegisterForm.vue`

```javascript
// 修改前
const formData = new FormData()
formData.append('file', form.materials.registrationForm[0].raw)
await uploadMaterial(registrationId.value, formData)

// 修改后
await uploadMaterial(
  registrationId.value, 
  'REGISTRATION_FORM',  // 材料类型
  form.materials.registrationForm[0].raw  // 文件对象
)
```

**需要修改3处**:
1. 报名表上传 (第935-940行) - materialType: 'REGISTRATION_FORM'
2. 成果报告书上传 (第943-948行) - materialType: 'REPORT'
3. 佐证材料上传 (第951-957行) - materialType: 'EVIDENCE'
