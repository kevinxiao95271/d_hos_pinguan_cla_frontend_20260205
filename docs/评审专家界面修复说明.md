# 评审专家界面修复说明 ✅

## 🔍 问题诊断

用户反馈：
1. ❌ 任务列表没有显示项目名称和医疗机构名称
2. ❌ 点击详情按钮后页面是空的，没有数据

## 📊 根本原因

### 问题1: 后端返回的数据结构是嵌套的

**实际返回:**
```json
{
  "success": true,
  "data": {
    "registration": {  // ← 数据在这里！
      "projectName": "护理交接班规范化-1",
      "groupType": "BASIC",
      "groupCode": "A1"
    },
    "members": [...],
    "activityInfo": {...},
    "projectSummary": {...}  // ← 注意是 projectSummary，不是 summary
  }
}
```

**前端原来的代码:**
```javascript
const data = detailRes.data
taskInfo.projectName = data.projectName  // ❌ 错误！应该是 data.registration.projectName
taskInfo.institutionName = data.institutionName  // ❌ 后端没有返回这个字段
```

### 问题2: institutionName 没有传递

- ✅ 任务列表接口(`GET /api/reviews/my-tasks`)包含 `institutionName`
- ❌ 详情接口(`GET /api/registrations/{id}`)不返回 `institutionName`
- ❌ 前端跳转时没有通过 query 传递 `institutionName`

---

## 🔧 修复方案

### 修复1: Tasks.vue - 跳转时传递完整信息

**修改文件:** `src/views/reviewer/Tasks.vue`

```javascript
// 修改 goToReview 和 viewScore 函数
const goToReview = (row) => {
  router.push({
    path: `/reviewer/review/${row.id}`,
    query: {
      registrationId: row.registrationId,
      projectName: row.projectName,
      institutionName: row.institutionName,  // ✅ 添加
      stage: row.stage  // ✅ 添加
    }
  })
}
```

### 修复2: Review.vue - 正确解析数据结构

**修改文件:** `src/views/reviewer/Review.vue`

#### 修改1: 从 query 中先获取基本信息
```javascript
const loadData = async () => {
  // ✅ 先从 query 中获取任务列表传过来的信息
  taskInfo.projectName = route.query.projectName || ''
  taskInfo.institutionName = route.query.institutionName || ''
  taskInfo.stage = route.query.stage || 'BOOK'
  
  // 然后加载详细信息...
}
```

#### 修改2: 正确提取嵌套数据
```javascript
// ✅ 正确保存项目详情
projectDetail.value = {
  registration: data.registration,        // ← 嵌套对象
  members: data.members || [],
  activityInfo: data.activityInfo,
  summary: data.projectSummary            // ← 注意字段名
}

// ✅ 从 registration 对象中提取数据
const reg = data.registration || {}
if (reg.projectName) {
  taskInfo.projectName = reg.projectName
}
if (reg.groupType) {
  taskInfo.groupType = reg.groupType
}
```

## 📝 数据结构对照表

| 字段 | 任务列表API | 详情API | 前端显示位置 |
|-----|------------|---------|------------|
| projectName | ✅ `data[].projectName` | ✅ `data.registration.projectName` | 任务列表、评分页 |
| institutionName | ✅ `data[].institutionName` | ❌ 无 | 任务列表、评分页 |
| groupType | ❌ 无 | ✅ `data.registration.groupType` | 评分页 |
| stage | ✅ `data[].stage` | ❌ 无 | 任务列表、评分页 |
| status | ✅ `data[].status` | ✅ `data.registration.status` | 任务列表 |
| members | ❌ 无 | ✅ `data.members[]` | 评分页详情面板 |
| activityInfo | ❌ 无 | ✅ `data.activityInfo` | 评分页详情面板 |
| summary | ❌ 无 | ✅ `data.projectSummary` | 评分页详情面板 |

**解决方案:** 通过 `route.query` 在页面跳转时传递任务列表中有但详情接口中没有的字段（如 `institutionName`、`stage`）。
