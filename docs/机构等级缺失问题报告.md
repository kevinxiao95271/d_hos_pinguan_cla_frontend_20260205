## 问题根源

❌ **后端API返回的数据中缺少机构等级字段**

前端代码正确实现了显示逻辑，但由于后端API返回的数据中：
- `institutionLevel` 字段为 `null`、`undefined` 或不存在
- `institution.level` 字段为 `null`、`undefined` 或不存在

导致前端只能显示默认值 `-`。

## 数据来源建议

机构等级数据应该来自 `pinguan_institution` 表的 `level` 字段。

建议后端在返回报名相关数据时：
1. 通过 JOIN 查询获取机构等级
2. 或在返回数据时补充机构对象的完整信息

**SQL示例**:
```sql
SELECT 
  r.*,
  i.level AS institutionLevel,
  i.code AS institutionCode,
  i.region AS institutionRegion
FROM pinguan_registration r
LEFT JOIN pinguan_institution i ON r.institution_id = i.id
WHERE ...
```
