## 🔧 前端修改内容

### 文件: `src/views/contestant/Competitions.vue`

#### 修改1: 导入并加载我的报名数据

```javascript
// 导入API
import { getMyRegistrations } from '@/api/registration'

// 添加数据
const myRegistrations = ref([])

// 并行加载赛事列表和我的报名
const loadData = async () => {
  try {
    loading.value = true
    
    const [competitionsRes, myRegsRes] = await Promise.all([
      getCompetitions(),
      getMyRegistrations()  // ← 新增：加载我的报名
    ])
    
    if (competitionsRes.success) {
      competitions.value = competitionsRes.data || []
    }
    
    if (myRegsRes.success) {
      myRegistrations.value = myRegsRes.data || []  // ← 保存我的报名
    }
  } finally {
    loading.value = false
  }
}
```

#### 修改2: 添加判断函数

```javascript
// 判断是否已报名该赛事
const isRegistered = (competitionId) => {
  return myRegistrations.value.some(
    reg => reg.competitionId === competitionId
  )
}

// 获取已报名的记录
const getMyRegistration = (competitionId) => {
  return myRegistrations.value.find(
    reg => reg.competitionId === competitionId
  )
}
```

#### 修改3: 更新按钮逻辑

```javascript
// 判断是否可报名
const canRegister = (item) => {
  // 只有报名阶段且未报名的才能报名
  return item.stage === 'REGISTER' && !isRegistered(item.id)
}

// 获取按钮文本
const getButtonText = (item) => {
  if (isRegistered(item.id)) {
    return '查看报名'  // ← 已报名显示
  }
  return canRegister(item) ? '立即报名' : '报名已结束'
}

// 处理按钮点击
const handleButtonClick = (item) => {
  if (isRegistered(item.id)) {
    // 已报名：跳转到报名详情
    const myReg = getMyRegistration(item.id)
    if (myReg) {
      router.push(`/contestant/registration/${myReg.id}`)
    }
  } else {
    // 未报名：跳转到报名页面
    router.push(`/contestant/register/${item.id}`)
  }
}
```

#### 修改4: 更新模板

```vue
<el-button
  :type="isRegistered(item.id) ? 'default' : 'primary'"
  :disabled="!canRegister(item.id) && !isRegistered(item.id)"
  @click="handleButtonClick(item)"
>
  {{ getButtonText(item) }}
</el-button>
```

## 🎯 功能说明

### 1. 按钮状态规则

| 赛事状态 | 按钮文本 | 按钮类型 | 是否禁用 | 点击行为 |
|---------|---------|---------|---------|---------|
| 已报名 | "查看报名" | default | 否 | 跳转到报名详情 |
| 报名中且未报名 | "立即报名" | primary | 否 | 跳转到报名页面 |
| 报名已结束 | "报名已结束" | primary | 是 | - |

### 2. 判断逻辑

```javascript
// 1. 是否已报名
isRegistered = myRegistrations.some(reg => reg.competitionId === competitionId)

// 2. 是否可报名
canRegister = stage === 'REGISTER' && !isRegistered

// 3. 按钮文本
if (isRegistered) → '查看报名'
else if (canRegister) → '立即报名'
else → '报名已结束'

// 4. 点击行为
if (isRegistered) → 跳转 /contestant/registration/{registrationId}
else → 跳转 /contestant/register/{competitionId}
```

### 3. 数据流

```
页面加载
    ↓
Promise.all([
    getCompetitions(),      → competitions
    getMyRegistrations()    → myRegistrations
])
    ↓
对比 competition.id 与 myRegistrations[].competitionId
    ↓
设置按钮状态
    ↓
用户点击按钮
    ↓
根据是否已报名跳转到不同页面
```

## 💡 技术要点

### 1. 并行加载数据

使用 `Promise.all` 同时加载多个接口，提升性能：

```javascript
const [competitionsRes, myRegsRes] = await Promise.all([
  getCompetitions(),
  getMyRegistrations()
])
```

**优点**:
- ⚡ 减少等待时间（并行而非串行）
- 🚀 提升用户体验

### 2. 响应式判断

使用 Vue 3 的响应式数据进行判断：

```javascript
const isRegistered = (competitionId) => {
  return myRegistrations.value.some(
    reg => reg.competitionId === competitionId
  )
}
```

**优点**:
- 🔄 数据变化时自动更新UI
- ✅ 无需手动刷新

### 3. 智能路由跳转

根据状态跳转到不同页面：

```javascript
if (isRegistered(item.id)) {
  router.push(`/contestant/registration/${myReg.id}`)  // 查看详情
} else {
  router.push(`/contestant/register/${item.id}`)       // 去报名
}
```

**优点**:
- 🎯 准确导航
- 📱 良好的用户体验
