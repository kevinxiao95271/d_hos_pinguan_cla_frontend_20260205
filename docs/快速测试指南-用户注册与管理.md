## 🐛 常见问题排查

### 问题1: 机构搜索返回空数据

**症状**: 选择地区后搜索无结果

**原因**: 地区名称不匹配

**解决**: 
- ❌ 不要使用"杭州市"、"温州市"（市级别）
- ✅ 使用"上城区"、"萧山区"（区县级别）
- 查看地区下拉列表，使用实际存在的地区名

---

### 问题2: 登录失败（手机号或密码错误）

**症状**: 输入正确的手机号和密码仍然失败

**原因**: 可能是旧系统测试账号（没有密码字段）

**解决**:
- 使用新注册的账号
- 或通过后端为旧账号设置密码

---

### 问题3: 注册时API返回500

**症状**: 填写完信息点击注册后报500错误

**原因**: 后端可能有异常

**解决**:
- 检查后端日志
- 确认机构ID是否存在
- 确认手机号未被占用

---

### 问题4: 创建评委权限不足（403）

**症状**: 点击"创建评委"后报403错误

**原因**: 当前登录用户角色不是OPS或COMMITTEE_ADMIN

**解决**:
- 使用OPS或COMMITTEE_ADMIN角色登录
- 或通过后端数据库修改用户角色

## 🔧 调试技巧

### 1. 查看网络请求

打开浏览器开发者工具（F12）-> Network标签

**关键请求**:
- `POST /api/institutions/search` - 机构搜索
- `GET /api/institutions/hot-regions` - 热门地区
- `GET /api/institutions/regions` - 地区列表
- `POST /api/auth/register` - 注册
- `POST /api/auth/login-with-password` - 登录
- `POST /api/admin/users/query` - 用户列表
- `POST /api/admin/users/reviewers` - 创建评委

**检查内容**:
- Request Payload（请求参数）
- Response（响应数据）
- Status Code（状态码）
- Response Time（响应时间）

---

### 2. 查看Console日志

打开浏览器开发者工具（F12）-> Console标签

**正常日志**:
```
✅ 加载热门地区成功
✅ 加载地区列表成功
✅ 加载等级列表成功
```

**错误日志**:

### 3. 查看localStorage

F12 -> Application -> Local Storage -> http://localhost:6039

**应包含**:
- `token`: JWT Token
- `userInfo`: 用户信息JSON
