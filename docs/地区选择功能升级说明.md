# 地区选择功能升级说明

## 📊 升级背景

后端机构地区数据已从**区县级别**扩展为**市级别智能映射**，现支持：

- **11个地级市**：杭州市、温州市、金华市、宁波市、台州市、绍兴市、丽水市、衢州市、嘉兴市、湖州市、舟山市
- **90个区县**：每个市下辖若干区县
- **36,076家机构**：覆盖浙江省全域医疗机构
- **智能扩展**：搜索"杭州市"自动匹配该市所有区县的机构（6,298家）

## 🎯 升级内容

### 1. 新增API接口

在 `src/api/institution.js` 中添加：

```javascript
/**
 * 获取城市列表（市级别，推荐使用）
 * 公开接口，无需Token
 */
export function getCities() {
  return request({
    url: '/institutions/cities',
    method: 'get',
    skipAuth: true
  })
}

/**
 * 获取指定城市的区县列表
 * 公开接口，无需Token
 */
export function getDistricts(city) {
  return request({
    url: '/institutions/districts',
    method: 'get',
    params: { city },
    skipAuth: true
  })
}
```

### 2. 更新机构选择器组件 (`src/components/InstitutionSelector.vue`)

#### 变更前（区县级别）
- 显示热门地区（90+个区县中的10个）
- 地区下拉框：90+个区县选项
- 搜索范围：固定区县

#### 变更后（市+区县两级）
- 显示11个城市快速选择
- 城市下拉框：11个市
- 区县下拉框（可选）：根据选中的城市动态加载
- 搜索范围：可按市（如"杭州市"6,298家）或按区县（如"上城区"1,091家）

#### 核心改进

**筛选器升级**：
```vue
<!-- 旧版 -->
<el-form-item label="地区">
  <el-select v-model="filters.region">
    <!-- 90+个区县 -->
  </el-select>
</el-form-item>

<!-- 新版 -->
<el-form-item label="城市">
  <el-select v-model="filters.city">
    <!-- 11个市 -->
  </el-select>
</el-form-item>

<el-form-item label="区县" v-if="filters.city">
  <el-select v-model="filters.district">
    <!-- 动态加载的区县 -->
  </el-select>
</el-form-item>
```

**快速选择**：
```vue
<!-- 旧版：热门地区 -->
<div class="hot-regions">
  <el-tag>上城区 (1091)</el-tag>
  <el-tag>萧山区 (1067)</el-tag>
  <!-- ... -->
</div>

<!-- 新版：城市选择 -->
<div class="city-selection">
  <el-tag>杭州市</el-tag>
  <el-tag>温州市</el-tag>
  <el-tag>宁波市</el-tag>
  <!-- 共11个市 -->
</div>
```

**搜索逻辑**：
```javascript
// 旧版：直接使用region
const params = {
  region: filters.region
}

// 新版：优先使用区县，其次使用城市
const params = {
  region: filters.district || filters.city || null
}
```

## 🎨 用户体验提升

### 升级前的问题
1. **地区选项过多**：90+个区县，难以查找
2. **热门地区不清晰**：区县级别的热门度不够直观
3. **筛选效率低**：需要在90+个选项中找到目标区县

### 升级后的优势
1. **快速定位**：11个市，一目了然
2. **分级筛选**：先选市，再选区县（可选），逐步缩小范围
3. **智能搜索**：
   - 选择"杭州市" → 搜索6,298家机构
   - 进一步选择"上城区" → 缩小到1,091家
   - 输入关键词 → 在已筛选范围内精确搜索

### 使用场景示例

#### 场景1：用户知道城市
```
1. 点击"杭州市"标签（或下拉选择）
2. 显示6,298家杭州的机构
3. 可以直接输入关键词搜索，如"人民医院"
```

#### 场景2：用户知道区县
```
1. 点击"杭州市"标签
2. 在"区县"下拉框中选择"上城区"
3. 缩小到1,091家机构
4. 输入关键词精确搜索
```

#### 场景3：用户只知道机构名称
```
1. 直接在关键词输入框输入"浙江省人民医院"
2. 系统在全部36,076家机构中搜索
3. 快速定位目标机构
```

## 🔍 后续优化建议

### 性能优化
1. **城市数据缓存**：城市列表（11个）可缓存到localStorage，减少API调用
2. **区县数据缓存**：已加载的区县列表可缓存
3. **搜索防抖**：关键词搜索已实现500ms防抖，可根据实际情况调整
