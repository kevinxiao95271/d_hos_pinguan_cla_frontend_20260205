## 🎯 用户场景

### 场景1：上传单个大文件
用户可以将多个文档打包成一个ZIP文件上传：
- 例如：将10个小图片打包成一个 `证明材料.zip` (15MB)
- 更方便组织和管理文件

### 场景2：保留目录结构
用户可以保留材料的目录结构：
```
佐证材料.zip
├── 医院证明/
│   ├── 证明1.pdf
│   └── 证明2.pdf
└── 数据统计/
    ├── 表格.xlsx
    └── 图表.png
```

### 场景3：混合上传
用户可以混合上传不同格式：
- 文件1：证明文件.pdf
- 文件2：数据图表.png
- 文件3：其他材料.zip
- 文件4：补充说明.docx
- 文件5：统计数据.rar

## 📝 技术说明

### MIME类型映射

浏览器会自动识别以下MIME类型：
- `.zip` → `application/zip`
- `.rar` → `application/x-rar-compressed` 或 `application/vnd.rar`

### 后端处理

后端MinIO存储和下载功能无需修改：
- MinIO支持任意二进制文件格式
- 下载时保持原文件名和格式
- Content-Type设置为 `application/octet-stream`
