# 入围管理功能 - 设计总结

## 核心需求（3个关键API）

### API 1: 书审排名 ⭐⭐⭐ 必需
```
GET /api/admin/reviews/rankings?competitionId=21&stage=BOOK
```
**返回**: 所有项目的书审得分、项目信息
**核心字段**: `registrationId`, `projectName`, `institutionName`, `groupType`, `avgTotal`

---

### API 2: 面谈排名 ⭐⭐⭐ 必需
```
GET /api/admin/reviews/rankings?competitionId=21&stage=INTERVIEW
```
**返回**: 所有项目的面谈得分（结构同API 1）
**核心字段**: `registrationId`, `avgTotal`

---

### API 3: 评审详情 ⭐⭐ 建议
```
GET /api/registrations/{id}/review-details
```
**返回**: 某个项目的书审和面谈详细评分、评委意见
**用途**: 点击"查看详情"时展示

---

## 页面功能

### 配置区
- 权重调整（书审/面谈比例，默认50%/50%）
- 入围比例（30%/40%/50%/自定义）
- 最低分数线

### 统计区
- 总项目数
- 已完成书审数
- 已完成面谈数
- 当前入围数（百分比）
- 手动增补数

### 列表区
- 综合排名
- 书审得分/面谈得分
- 项目信息

- 入围状态
- 操作（查看详情/增补入围/取消入围）
