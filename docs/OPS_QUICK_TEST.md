## 常见问题排查

### 问题1: 页面显示空列表

**检查项**:
1. 打开 Network 标签，查看请求状态码
2. 如果是 400 错误，说明修复未生效，需要刷新页面
3. 如果是 401 错误，说明登录过期，需要重新登录

**解决方法**:
```
1. 硬刷新页面: Ctrl + Shift + R (Windows) 或 Cmd + Shift + R (Mac)
2. 清除缓存: Ctrl + Shift + Delete
3. 重新登录
```

---

### 问题2: 请求返回 400 错误

**原因**: 前端代码未更新或浏览器缓存

**解决方法**:
```bash
# 1. 确认前端服务正在运行
# 查看终端是否有 Vite 服务运行

# 2. 如果服务未运行，重新启动
npm run dev

# 3. 硬刷新浏览器
Ctrl + Shift + R
```

---

### 问题3: 请求返回 401 错误

**原因**: Token 过期或未登录

**解决方法**:
```javascript
// 在浏览器 Console 中执行
localStorage.clear()
location.reload()
// 然后重新登录
```

---

### 问题4: 看不到数据但请求成功

**检查项**:
1. 打开 Console 标签
2. 执行以下命令查看数据：

```javascript
// 查看用户列表数据
console.log('users:', users.value)

// 查看报名列表数据
console.log('registrations:', registrations.value)
```

**如果数据存在但不显示**:
- 可能是前端渲染问题
- 检查是否有 v-if 条件隐藏了数据
- 检查是否有 CSS 样式问题
