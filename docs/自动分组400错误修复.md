## 📋 问题描述

**错误信息**:

## 🔍 问题诊断

### 1. 前端发送的参数 ❌

**修复前的代码**:
```javascript
const res = await autoGroupRegistrations({
  competitionId: filters.competitionId  // 只传了1个参数
})
```

### 2. 后端期望的参数 ✅

通过测试脚本验证，后端需要**3个必需参数**：

| 参数 | 类型 | 说明 | 示例 |
|-----|------|------|------|
| `competitionId` | Integer | 赛事ID | 21 |
| `groupPrefix` | String | 分组前缀 | "A" |
| `groupSize` | Integer | 每组人数 | 10 |

### 3. 测试结果

```

  [FAIL] 失败！状态码: 400
  错误信息: "参数校验失败"

测试 #4: 完整参数

```

## 🔧 修复方案

### 修复代码

**文件**: `src/views/committee/book/Registration.vue`

**修复前** ❌:
```javascript
const autoGroup = async () => {
  try {
    await ElMessageBox.confirm('确定要自动分配分组吗？', '提示', {
      type: 'warning'
    })
    
    const res = await autoGroupRegistrations({
      competitionId: filters.competitionId  // ❌ 缺少2个参数
    })
    
    if (res.success) {
      ElMessage.success('自动分组成功')
      loadRegistrations()
    }
  } catch (error) {
    if (error !== 'cancel') {
      ElMessage.error('自动分组失败')
    }
  }
}
```

**修复后** ✅:
```javascript
const autoGroup = async () => {
  try {
    await ElMessageBox.confirm(
      '确定要自动分配分组吗？将按每组10人自动分配到A组系列（A1、A2、A3...）',
      '提示',
      {
        type: 'warning',
        confirmButtonText: '确定',
        cancelButtonText: '取消'
      }
    )
    
    const res = await autoGroupRegistrations({
      competitionId: filters.competitionId,
      groupPrefix: 'A',  // ✅ 添加分组前缀
      groupSize: 10      // ✅ 添加每组人数
    })
    
    if (res.success) {
      ElMessage.success('自动分组成功')
      loadRegistrations()
    } else {
      ElMessage.error(res.message || '自动分组失败')
    }
  } catch (error) {
    if (error !== 'cancel') {
      console.error('自动分组失败:', error)
      ElMessage.error('自动分组失败')
    }
  }
}
```

## 🎯 功能说明

### 自动分组逻辑

**分组规则**:
- **分组前缀**: `A`（固定，书审阶段使用A系列）
- **每组人数**: `10`人
- **分组结果**: A1、A2、A3、A4...

**示例**:
```
假设有33个报名项目：
- 前10个 → A1组
- 11-20个 → A2组
- 21-30个 → A3组
- 31-33个 → A4组
```

**修复后的提示文本**:
```

将按每组10人自动分配到A组系列（A1、A2、A3...）
```

**按钮**:
- ✅ 确定 - 执行自动分组
- ❌ 取消 - 取消操作
