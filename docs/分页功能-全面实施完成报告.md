## 🔧 技术实现

### 核心Composable
**文件**: `src/composables/usePagination.js`

**功能**:
- 管理分页状态（currentPage, pageSize, totalCount）
- 自动识别分页和非分页响应
- 提供统一的分页参数获取
- 提供重置分页的方法

**使用示例**:
```javascript
import { usePagination } from '@/composables/usePagination'

const {
  currentPage,
  pageSize,
  totalCount,
  pageSizes,
  showPagination,
  extractDataList,
  resetPagination,
  getPaginationParams
} = usePagination({ defaultPageSize: 50 })

// 加载数据时
const loadData = async () => {
  const res = await api({ ...filters, ...getPaginationParams() })
  if (res.success) {
    list.value = extractDataList(res.data)
  }
}

// 重置筛选时
const resetFilters = () => {
  // ... 重置筛选条件
  resetPagination()
  loadData()
}
```

### UI组件
```vue
<el-pagination
  v-if="showPagination"
  v-model:current-page="currentPage"
  v-model:page-size="pageSize"
  :total="totalCount"
  :page-sizes="pageSizes"
  layout="total, sizes, prev, pager, next, jumper"
  @size-change="loadData"
  @current-change="loadData"
/>
```

### 样式
```scss
.pagination-container {
  margin-top: 20px;
  display: flex;
  justify-content: flex-end;
}
```
