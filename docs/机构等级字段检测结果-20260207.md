## 📝 数据说明

### 机构等级可能值
根据中国医院分级标准：
- 三级甲等、三级乙等、三级丙等
- 二级甲等、二级乙等、二级丙等
- 一级甲等、一级乙等、一级丙等
- 未定级 / null

### 数据处理建议
1. **后端存储**: 字符串类型，允许 null
2. **前端显示**: 
   - 有值时：直接显示，如 "三级甲等"
   - null 时：显示 "未填写" 或 "-"
3. **筛选功能**: 支持按等级筛选（可选）
