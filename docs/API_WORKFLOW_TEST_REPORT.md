## 4. 前端功能检查

### 4.1 参赛者报名功能检查

#### 现有功能
- ✅ 报名详情展示 (`src/views/contestant/MyCompetition.vue`)
  - 机构信息展示
  - 项目信息展示
  - 参与人员列表
  - 辅导员列表
  - 书审/面谈/决赛结果查看

#### ❓ 需要确认的功能

**1. 草稿保存功能**
```
问题：是否支持草稿保存？
现状：未发现明确的草稿保存UI
建议：
  - 报名表单应支持"保存草稿"按钮
  - 草稿可以多次编辑
  - 草稿不会提交到评审流程
```

**2. 已提交报名的保护**
```
问题：已提交的报名是否禁止修改？
现状：MyCompetition.vue 是只读视图，没有编辑功能
建议：
  - 如果有报名编辑页面，需要检查状态
  - SUBMITTED 状态应该禁用编辑
  - 应该显示灰色或禁用状态
```

**3. 报名列表页面**
```
问题：是否有报名列表页面显示所有报名？
现状：只看到单个报名的详情页
建议：
  - 应该有一个列表页显示所有报名记录
  - 区分草稿和已提交
  - 草稿显示"编辑"和"提交"按钮
  - 已提交显示"查看"按钮，禁用编辑
```
