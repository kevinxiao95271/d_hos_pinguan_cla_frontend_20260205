## 💡 如果遇到问题

### 问题1: 职称列显示为空

**可能原因**:
- 后端服务未重启
- 浏览器缓存了旧数据

**解决方法**:
```bash
# 1. 确认后端服务已重启
# 2. 清除浏览器缓存（Ctrl + F5 强制刷新）
# 3. 重新登录
```

### 问题2: 职称显示"undefined"

**可能原因**:
- 该评委数据库中未设置职称

**解决方法**:
- 检查数据库 `users` 表中该评委的 `title` 字段是否有值
- 如果为空，需要更新数据库

### 问题3: 部分评委有职称，部分没有

**说明**: 这是正常现象
- 早期创建的评委可能未设置职称
- 新创建的评委有职称
- 建议统一补充所有评委的职称信息
