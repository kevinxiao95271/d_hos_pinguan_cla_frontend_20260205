# 面谈页面筛选问题排查指南

**问题描述**: 面谈页面显示了非进阶组的参赛项目

**测试日期**: 2026-02-07

---

## ✅ 后端API测试结果

**测试脚本**: `scripts/test_interview_filter.py`

**测试结果**:
- API: `GET /api/admin/registrations/filter?competitionId=21&groupType=ADVANCED&page=1&size=50`
- 返回: 11个项目，**全部是进阶组** ✅
- 结论: **后端API筛选逻辑正确**

---

## 🔍 前端排查步骤

### 1. 打开浏览器开发者工具

1. 按 `F12` 打开开发者工具
2. 切换到 **Network（网络）** 标签
3. 筛选 `Fetch/XHR` 请求

### 2. 进入面谈页面

访问以下任一页面：
- **面谈评委分配**: `http://localhost:6039/committee/interview/reviewer`
- **面谈分组**: `http://localhost:6039/committee/interview/group`

### 3. 检查API请求参数

在 Network 面板中找到 `/api/admin/registrations/filter` 请求，检查：

#### ✅ 正确的请求参数应该包含：
```
competitionId: 21
groupType: ADVANCED    <-- 必须有这个参数
page: 1
size: 50
```

#### ❌ 如果缺少 `groupType` 参数：
```
competitionId: 21
page: 1
size: 50
// 缺少 groupType，会返回所有组别！
```

### 4. 查看请求URL

在开发者工具的 Network 面板中，点击该请求，查看：
- **Request URL**: 应该类似 `http://localhost:6031/api/admin/registrations/filter?competitionId=21&groupType=ADVANCED&page=1&size=50`
- **Query String Parameters**: 应该包含 `groupType: ADVANCED`

## 🐛 可能的问题原因

### 原因1: 分页后参数丢失

**症状**: 第1页正常，切换到第2页后显示了其他组别

**原因**: 在切换页码时，`groupType` 参数没有被正确传递

**检查位置**:
```vue
<!-- src/views/committee/interview/Reviewer.vue -->
<el-pagination
  @size-change="loadRegistrations"
  @current-change="loadRegistrations"
/>
```

**确认**: `loadRegistrations` 函数是否正确传递了 `registrationFilter.value`（包含 `groupType: 'ADVANCED'`）

---

### 原因2: 筛选条件被重置

**症状**: 使用筛选器后显示了其他组别

**原因**: 筛选条件变化时，`groupType` 被误清空

**检查位置**:
```javascript
// src/views/committee/interview/Reviewer.vue
const resetRegistrationFilter = () => {
  regResetPagination()
  registrationFilter.value = {
    competitionId: competitionId.value,
    groupType: 'ADVANCED',  // 确认这一行存在
    groupCode: '',
    projectName: ''
  }
  loadRegistrations()
}
```

---

### 原因3: 响应式数据未生效

**症状**: 页面加载时显示了其他组别

**原因**: `registrationFilter.groupType` 初始化时未正确设置

**检查位置**:
```javascript
// src/views/committee/interview/Reviewer.vue
const registrationFilter = ref({
  competitionId: competitionId.value,
  groupType: 'ADVANCED',  // 确认这一行存在且值正确
  groupCode: '',
  projectName: ''
})
```
