## 剩余优化空间

### 1. 机构名称筛选 (1.456秒 → 目标 < 0.5秒)

#### 方案A: 使用全文索引
```sql
-- MySQL 5.7+
CREATE FULLTEXT INDEX idx_institution_name_fulltext 
ON registrations(institution_name);

-- 查询改为
SELECT * FROM registrations 
WHERE MATCH(institution_name) AGAINST('医院' IN BOOLEAN MODE);
```

**预期效果**: 1.456秒 → 0.3秒 (⬇️ 79%)

---

#### 方案B: 使用Elasticsearch
```java
// 将报名数据同步到ES
@Document(indexName = "registrations")
public class RegistrationDocument {
    @Field(type = FieldType.Text, analyzer = "ik_max_word")
    private String institutionName;
    // ...
}

// 搜索
SearchHits<RegistrationDocument> hits = elasticsearchTemplate
    .search(QueryBuilders.matchQuery("institutionName", "医院"), 
            RegistrationDocument.class);
```

**预期效果**: 1.456秒 → 0.1秒 (⬇️ 93%)

---

#### 方案C: 前端优化 - 防抖
```javascript
// 用户输入时不立即查询，等待500ms后再查询
const debouncedSearch = debounce(() => {
  loadRegistrations()
}, 500)

watch(() => filters.institutionName, () => {
  debouncedSearch()
})
```

**预期效果**: 减少不必要的查询，改善用户体验
