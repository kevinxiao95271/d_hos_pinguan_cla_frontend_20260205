## 🔍 问题诊断

### 错误信息
```
For input string: "undefined"
Failed to load resource: /api/registrations/undefined
🔴 请求错误: 400 /registrations/undefined
```

### 根本原因

**两个问题：**

1. **路由参数名不匹配**
   ```javascript
   // 路由配置（src/router/index.js）
   path: 'registration/:id',  // ← 参数名是 'id'
   
   // MyCompetition.vue 第168行
   const registrationId = ref(route.params.registrationId)  // ❌ 错误！
   ```

2. **后端返回的是嵌套数据结构**
   ```json
   {
     "data": {
       "registration": { ... },  // ← 基本信息在这里
       "members": [...],
       "activityInfo": {...}
     }
   }
   ```

---

## 🔧 修复方案

### 修复1: 路由参数名

**文件:** `src/views/contestant/MyCompetition.vue`

```javascript
// ❌ 修复前
const registrationId = ref(route.params.registrationId)

// ✅ 修复后
const registrationId = ref(route.params.id)  // 匹配路由配置
```

## ⚠️ 注意事项

### 1. 路由参数一致性

确保所有使用该路由的地方参数名一致：

```javascript
// ✅ 正确
router.push(`/contestant/registration/${id}`)
route.params.id

// ❌ 错误
router.push(`/contestant/my-competition/${id}`)
route.params.registrationId
```

### 2. 数据结构嵌套

后端返回的数据是嵌套的，必须正确提取：

```javascript
// ✅ 正确
data.registration.projectName
data.projectSummary

// ❌ 错误
data.projectName
data.summary
```

### 3. 字段名差异

注意前后端字段名的差异：

| 前端期望 | 后端返回 |
|---------|---------|
| `summary` | `projectSummary` |
| `institutionName` | 需要从 `/api/institutions/{id}` 获取 |
