# 评委负荷字段缺失问题报告

## 🐛 问题描述

在评委列表页面（书审/面谈/决赛评委分配页面），所有评委的"负荷"列都显示为 **0**，但实际上很多评委身上有任务。

## 📊 问题分析

### API端点
```
GET /api/admin/reviewers?competitionId=21
```

### 前端期望字段
```javascript
// 前端代码：src/views/committee/book/Reviewer.vue:169-171
<el-tag :type="getLoadTagType(row.currentLoad)" size="small">
  {{ row.currentLoad ?? 0 }}
</el-tag>
```

**前端期望字段名：`currentLoad`**

### 后端实际返回字段

经过API测试，后端返回的评委数据**没有包含负荷相关字段**：

```json
{
  "id": 6,
  "phone": "13800000084",
  "name": "李明华",
  "title": "Test Title",
  "institutionId": 1,
  "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
  "reviewerGroupCode": "A1",
  "interviewGroupCode": "A1",
  "expertBackground": "MEDICAL"
}
```

### ❌ 缺失的字段

后端**完全没有返回**以下任何负荷相关字段：
- ❌ `currentLoad` （前端期望的字段）
- ❌ `load`
- ❌ `taskCount`
- ❌ `reviewCount`
- ❌ `workload`

### 🚨 问题根源

**后端API没有返回负荷字段，导致前端无法显示评委的任务负荷。**

## 📝 给后端的修复建议

### 需要添加的字段

在 `GET /api/admin/reviewers` 的返回数据中，**每个评委对象需要增加 `currentLoad` 字段**：

```json
{
  "id": 6,
  "phone": "13800000084",
  "name": "李明华",
  "title": "Test Title",
  "institutionId": 1,
  "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
  "reviewerGroupCode": "A1",
  "interviewGroupCode": "A1",
  "expertBackground": "MEDICAL",
  "currentLoad": 5  // ⭐ 需要添加这个字段
}
```

### 字段计算规则

`currentLoad` 应该统计该评委在当前竞赛中的**所有任务数量**，包括：

1. ✅ **未分配的任务** (PENDING)
2. ✅ **已评分的任务** (SCORED) ⭐ **重点：已评分的也要算**
3. ✅ **待重评的任务** (RETURNED)
4. ✅ **进行中的任务** (IN_PROGRESS)

**不应该排除已评分的任务！**评委的历史工作量也是负荷的一部分。

### SQL查询示例（参考）

```sql
SELECT 
    r.id,
    r.phone,
    r.name,
    r.title,
    r.institution_id,
    i.institution_name,
    r.reviewer_group_code,
    r.interview_group_code,
    r.expert_background,
    COUNT(rt.id) as current_load  -- 统计任务数
FROM reviewers r
LEFT JOIN review_tasks rt ON rt.reviewer_id = r.id 
    AND rt.competition_id = ?  -- 当前竞赛
LEFT JOIN institutions i ON i.id = r.institution_id
WHERE r.competition_id = ?  -- 当前竞赛的评委
GROUP BY r.id
```
