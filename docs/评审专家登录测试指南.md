## 🔍 问题排查

### 如果看不到项目信息

#### 检查1: URL参数
打开浏览器控制台（F12），输入：
```javascript
console.log('taskId:', location.pathname.split('/').pop());
console.log('registrationId:', new URLSearchParams(location.search).get('registrationId'));
```

**预期输出:**
```
taskId: 115
registrationId: 106  ← 必须有这个！
```

#### 检查2: 网络请求
1. 打开浏览器开发者工具（F12）
2. 切换到 **Network** 标签
3. 刷新页面
4. 查找以下请求：
   - `GET /api/reviews/my-tasks` - 应该返回 200
   - `GET /api/registrations/106` - 应该返回 200

#### 检查3: 控制台日志
在 **Console** 标签查找：
- ✅ "项目详情加载成功" - 表示数据加载正常
- ❌ 红色错误 - 表示有问题

#### 检查4: 数据结构
在控制台输入：
```javascript
// 检查路由参数
console.log('route.query:', JSON.stringify($router.currentRoute.value.query));

// 检查是否调用了正确的API
console.log('检查Network标签，确认调用了 /api/registrations/106');
```
