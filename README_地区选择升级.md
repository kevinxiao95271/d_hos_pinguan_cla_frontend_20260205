## 🔑 核心代码变更

### API调用变更

#### 升级前
```javascript
import { getHotRegions, getAllRegions } from '@/api/institution'

// 加载热门地区（10个区县）
const hotRegions = await getHotRegions(10)

// 加载所有地区（90+个区县）
const allRegions = await getAllRegions()
```

#### 升级后
```javascript
import { getCities, getDistricts } from '@/api/institution'

// 加载城市列表（11个市）
const cities = await getCities()

// 动态加载区县（如杭州市13个区县）
const districts = await getDistricts('杭州市')
```

### 搜索逻辑变更

#### 升级前
```javascript
const params = {
  region: filters.region,  // 直接使用区县
  // ...
}
```

#### 升级后
```javascript
// 优先级: 区县 > 城市
let region = null
if (filters.district) {
  region = filters.district    // 如"上城区"
} else if (filters.city) {
  region = filters.city         // 如"杭州市"
}

const params = {
  region: region,
  // ...
}
```
