## 快速测试命令（浏览器控制台）

打开浏览器开发者工具（F12），在Console中执行以下命令查看API返回的数据：

### 检查我的报名详情
```javascript
// 在"我的报名"页面执行
fetch('/api/registrations/my', {
  headers: { 'Authorization': localStorage.getItem('token') }
})
.then(r => r.json())
.then(d => console.log('institutionLevel:', d.data[0]?.institutionLevel))
```

### 检查书审分组列表
```javascript
// 在"书审分组"页面执行
fetch('/api/admin/registrations/filter?page=0&size=1', {
  headers: { 'Authorization': localStorage.getItem('token') }
})
.then(r => r.json())
.then(d => {
  const first = d.data?.content?.[0] || d.data?.[0];
  console.log('institutionLevel:', first?.institutionLevel);
})
```

### 检查评委任务列表
```javascript
// 在"评审任务"页面执行
fetch('/api/reviews/my-tasks', {
  headers: { 'Authorization': localStorage.getItem('token') }
})
.then(r => r.json())
.then(d => console.log('institutionLevel:', d.data[0]?.institutionLevel))
```

## 问题排查

如果某个场景显示 `-` 或空白：

1. **打开开发者工具（F12）**
2. **切换到 Network 标签**
3. **刷新页面或重新进入该页面**
4. **找到对应的API请求**
5. **查看 Response**，确认返回数据中是否有 `institutionLevel` 字段
6. **截图并记录**
