# 🔍 浏览器调试命令 - 立即诊断问题

## 步骤1: 检查当前页面URL

在浏览器控制台（F12 → Console）输入：

```javascript
console.log('当前URL:', location.href)
console.log('registrationId:', new URLSearchParams(location.search).get('registrationId'))
console.log('projectName:', new URLSearchParams(location.search).get('projectName'))
console.log('institutionName:', new URLSearchParams(location.search).get('institutionName'))
```

**预期输出:**
```
当前URL: http://localhost:6039/reviewer/review/115?registrationId=106&projectName=护理交接班规范化-1&institutionName=浙江大学医学院附属第一医院&stage=BOOK&isViewMode=true
registrationId: 106  ← 必须有值！
projectName: 护理交接班规范化-1
institutionName: 浙江大学医学院附属第一医院
```

**如果 registrationId 是 null:**
- ❌ 说明跳转时没有传递参数
- ✅ 需要检查前端代码是否已更新

## 步骤3: 检查前端代码是否已更新

在任务列表页面，在控制台输入：

```javascript
// 检查页面源代码
fetch('/src/views/reviewer/Tasks.vue')
  .then(r => r.text())
  .then(code => {
    if (code.includes('isViewMode')) {
      console.log('✅ 代码已更新：包含 isViewMode')
    } else {
      console.log('❌ 代码未更新：不包含 isViewMode')
      console.log('⚠️ 请检查前端服务是否已重启，或者浏览器缓存是否已清除')
    }
    
    if (code.includes('institutionName: row.institutionName')) {
      console.log('✅ 代码已更新：传递 institutionName')
    } else {
      console.log('❌ 代码未更新：未传递 institutionName')
    }
  })
```

## 步骤5: 强制刷新

1. **清除浏览器缓存并刷新:**
   - Windows: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

2. **或者清除所有缓存:**
   - 按 `F12` 打开开发者工具
   - 右键点击刷新按钮
   - 选择"清空缓存并硬性重新加载"

3. **或者使用无痕模式:**
   - `Ctrl + Shift + N` (Chrome)
   - 重新登录测试

## 🎯 根据输出判断问题

### 情况1: registrationId 是 null
**原因:** 跳转时没有传递参数
**解决:** 
1. 确认前端代码已保存
2. 重启前端服务 (`npm run dev`)
3. 强制刷新浏览器 (`Ctrl+Shift+R`)

### 情况2: 任务列表中没有 registrationId
**原因:** 后端数据问题
**解决:** 运行 `python scripts/debug_reviewer_frontend.py` 检查后端

### 情况3: 代码检查显示"未更新"
**原因:** 前端代码未生效
**解决:**
1. 确认文件已保存
2. 检查是否有编译错误
3. 重启前端服务

### 情况4: 一切正常但还是报错
**原因:** 可能是 Review.vue 中的逻辑问题
**解决:** 在详情页控制台输入：
```javascript
console.log('route.query:', $route.query)
console.log('registrationId:', $route.query.registrationId)
```
